# 0号文档 — 匹克球约球工具（暂名）

## 一句话
微信里约匹克球的工具（H5 + 小程序），谁都能张罗球局，把"想打"到"打爽、下次还来"整条链管起来。

核心循环：建局 → 报名 → 签到 → 轮转上场/记分 → 积分沉淀 → 留打球意向 → 凑人订场成局 → 再来。

规范与体验：符合腾讯小程序和隐私规范；头像这些球员档案做有味道，大家愿意从微信群挪过来。

1. **组织**：谁想打球都能开一局——定时间地点、召集人、管报名，不用再靠微信群接龙。
2. **到场**：球友报名、签到、早退都有记录，来没来、几点走的，清清楚楚。
3. **现场**：人多了安排谁上场、谁休息、和谁一边，比分随手记，不打乱仗。
4. **沉淀**：每场球的成绩长期累积成水平积分，谁大概什么水平有数，配对轮转有依据，积分算得不合理还能自己纠偏。
5. **长期**：把每个人模糊的打球规划，变成逐步清晰、有足够人数的打球订场安排——球友各自留个意向（大概什么时候想打、多久打一次），相似的意向往一块儿凑，人数凑够了，订场就从"赌一把"变成"水到渠成"。

## 解决问题
1. 接龙报名乱：谁报了、谁临时退了、满没满员。
2. 到场情况黑箱：谁来了、谁早退了不清楚。
3. 上场靠吼：人多场少，有人场场上、有人坐穿板凳。
4. 战绩即打即忘：没人记分，或记在谁脑子里就丢在谁那里，水平全凭"我觉得"。
5. 配对失衡：新手高手混着搭，局的质量差，双方都不过瘾——没有水平依据做均衡。
6. 订场靠赌：不确定能来几个，不敢提前订场；订了又常来不够人，场地费亏着分摊。
7. 打球没有规律：想固定每周打的人，凑不出稳定的搭子和局，各自模糊的意向碰不上。
8. 分摊靠脑：场地费谁垫的、谁转了谁没转，全靠人脑记，一周就糊——每场的分摊该自动算清楚。

微信（H5+小程序）为主，账号体系不绑死微信、预留 app 多端
## 术语
（以下术语在文档、代码、接口命名中一一对应使用，不用同义词。）
- **球局**：一场有组织的打球活动（不叫"活动/赛事"）。
- **场地**：租下来打球的那块物理场，有号——订场登记的"3号、5号"就是它。一个球局可 1~n 片同时开。量词只用"片"：三片场地、退一片（不叫"球场"；代码里 court 只指它）。
- **对局**：一片场地上两队争一个比分的比赛，两（单打）或四（双打）人，从开打记分到结束对局算一场。量词只用"场"：一场对局（不叫"比赛/场次/局"；片只数场地，场才数对局）。
- **结束对局**：一场对局打完的确认动作——点胜方、落积分、排下一场对局（不叫"终局"，避免和球局错位）。
- **散场**：整个球局打完收工（不叫"终局/结束"——那是结束对局的事）。
- **战报**：一场球局散场后的全场记录——每场对局谁跟谁、几比几、谁赢了、积分涨跌，附名单与考勤（考勤分权可见）。装它的页面即回看页（球友口中的"比赛汇总页"），散场当场、打球记录、分享链接三路可看。
- **开账**：现场账本开张的动作（口语常说"开场"）——账开张后才能签到、轮转、记分；账没开，状态显示"进行中"也进不去打。
- **组织者**：球局发起人，只管自己的局（不叫"管理员"）。
- **管理员**：现场里组织者临时封的帮手，与组织者同权处理现场事项（不叫"裁判"，也不是"组织者"的别名）。现场账开张后第一个签到的球友自动担任管理员，组织者到场可收回（散场即止）。
- **轮转**：谁上场、谁休息、和谁配对（不叫"排队"）。
- **DUPR 积分**：核心战力数——战绩长期沉淀的水平数字（2.0–8.0 三位小数），管均衡配对、榜单、段位（不叫"评分"；口径见 1.4）。
- **积分**：Elo 娱乐积分——结束对局的即时涨跌反馈、月度涨跌看它；与 DUPR 积分同一场结束对局双写两本（双轨制 2026-10-07，详见 1.4）。
- **打球意向**：大概什么时候想打、多久打一次（不叫"预约"）。
- **成局**：意向凑够人、订场落地（不叫"成团"）。
- **轮换方式**：现场「谁下场、怎么补人上场」的规矩——谁上谁下不再靠手工维护顺序账本，每次按场上场下每个人的当前状态当场算排位（连打了几场、等了多久、今晚打了几场、到场先后，连战在同条件下抢先）；组合是：「谁下」（全上全下 / 输家下 / N人下·连打多先下）＋「怎么配」（按候场队序 / 均衡配对 / 轮换优先 / 胜负均衡）＋全场统一的连打上限（0=不限）。旧三模式映射：赢家留场＝输家下、纯轮转＝全上全下。
- **装扮**：球友穿在身上的形象——**头像**与**卡背**两件，头像全站一律圆形透明圆章；分公共基础（人人随便换）、荣誉成就（打球攒出来：参与对局场数 / DUPR 水平台阶 / 张罗且正常散场的局数）、专属定制（官方授予、对普通人隐身）三档；荣誉款没解锁可试穿不可保存，达标即终身拥有、掉分不收回（口径见 1.9）。
- **卡背**：铺在名片、档案、榜单行、局卡、名单格等卡片位置的个人背景图——一件卡背一份原图走全站，各位置按取景规则裁着铺、归属一条规则「每张卡每格每行铺它的主人」（不叫「皮肤/背景图」；铺法总账见 1.9 附录）。
- **解锁清单**：账号上记的「已拥有装扮编号」一本账——公共款不进清单（人人默认可用），荣誉款靠进装扮页时顺手核算达标写入，定制款靠运维发卡；除运维收卡外只增不减。
- **均衡配对**：上场的人按 DUPR 积分强弱搭配分队——强配弱，不让两个高手挤同一边、两个差距大的挤另一边；同一批人再次同场时自动换次优分法，不复读。
- **示例局**：现场页在「没有进行中的球局」时摆出的一局内置假局，给访客和无局球友跟着提示亲手学现场玩法——标着「示例」常驻、零真人数据、动作不产生真实记录（口径见 2.7）。
