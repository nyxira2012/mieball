# 契约总则 — 前后端接口的度量衡

> 一页纸。所有域的后端规格（1.x）动工前先读这里；各域的契约细节写在各域规格的技术设计章节，本文只定跨域不变的部分。
> 改本文任何一条 = 改决定：先改本文，再记一条开发日志，然后才动代码。
>
> **真值原则**：字段**形状**的真值在代码里——后端 FastAPI 自动生成的 `/docs` 接口文档 + 前端 `src/api` 的类型；本文只写代码说不清的**语义**和**裁决**。文档是账本，不是图纸。
>
> 文中所引先例都是账号域（1.1）的实际代码，不是设想。

## 1. 命名

- **线上（接口进出）一律 snake_case**，后端零转换直出；前端 api 层的接口类型**原样镜像线上形状**，不做转换。先例：后端 `device_marker`/`card_bg`（app/api/routes/auth.py），前端 `AccountView.card_bg`（src/api/auth.ts）。
- 字段名用完整可读单词，不用字母缩写。mock 里的 `t`/`d`/`tb`/`sa`/`sb` 是原型遗产，各域接线时在 types.ts 同步换成可读名（如 `time`/`date`/`bucket`/`scoreA`），靠 type-check 全量兜底——缩写名一旦上线就再也甩不掉，趁接线一次换清。
- store/页面/组件内部叫什么名字，不归本文管。

## 2. 时间

- **接口进出一律绝对时间，ISO 8601 带时区**，本项目统一北京时间：`2026-10-06T19:00:00+08:00`。统一东八区而非 UTC：clock 的日切/限频窗口本就按本地日期算（app/core/clock.py），少一层换算少一类错位 bug。
- 「今晚 19:00」这类**相对表达只允许存在于输入框**：前端解析换算（utils/time.ts）后提交绝对时间；后端只收绝对时间、只回绝对时间。
- 展示文案（「周三 20:00」「还有 2 小时」）归前端，后端不产中文文案。
- 日期边界判断（日切、限频、截止到点）以服务器时间为准。

## 3. 错误

- 失败体统一 `{"error": {"code", "message"}}`。先例：app/core/errors.py + src/api/http.ts。
- **code 是机器分支的唯一钥匙**：英文蛇形（`phone_taken`/`sms_cooldown`），一旦上线永不变名。message 是中文人话，只用于展示，**前端禁止解析 message 做逻辑**。
- 前端遇到没见过的 code：显示 message 兜底，不许崩（errText 已是单一源）。
- 新增错误码 = 后端 errors.py 加具名构造器 + 域规格错误码表登记，**两边同步才算数**。
- 成功体不包 envelope，直接就是业务字段：`{"token": ..., "account": ...}` 或 `{"ok": true}`。

## 4. 动词与权限

- HTTP 只用 **GET / POST**，写操作一律 POST。不用 PATCH/PUT/DELETE：uni.request 小程序端不支持 PATCH（先例：apiUpdateProfile 注释），与其留分端例外不如统一。
- 身份一律 `Authorization: Bearer <token>` 请求头；钥匙不进 URL、不进 body。
- 写权限总则（**后端校验是安全边界，前端拦截只是体验**）：
  - 球局管理动作（改局/截止/取消/邀请/订场）——只有组织者；
  - 现场状态（开局/记分/换人/规则/终局结算）——组织者单一写，其他人只读；现场读响应带轮次/版本字段（LiveState.round 的线上对应物），为将来万一开放多人写留余地；
  - 个人自己的事（报名/退局/意向/到场/退场）——本人写本人的。
- 修改类接口对重复提交幂等（先例：logout 没带钥匙也回 ok）。

## 5. 单位与格式

- **id 一律整数**（先例：Account.id；mock 的 User.id/Game.id 同）。
- **金额一律人民币元、整数**。fee 是总价口径（先例：mock fee=720），不存分、不存小数；摊派出小数时归整，规则落各域规格。
- 「用户确实填了这一项」用显式布尔标志（`nickname_set`），不做值推断（1.1 的 D5 裁决，新域沿用）。
- 列表暂不分页、全量返回、带稳定排序（新到旧或 id 序，写进各域规格）；将来要分页加 page 参数，不动旧字段。

## 6. 契约怎么长牙齿

- 后端 pytest 锁响应形状（账号域测试是样板）——改坏契约，测试当场红；
- 前端 type-check 锁消费——改名漏改，编译不过；
- 各域后端规格的技术设计章节必须含**五件套**：字段表 / 接口清单 / 错误码表 / 状态机 / 不变承诺；细则引用本文，不重复本文。
