# 6.2. 状态与规则总表（成文法）

> **双面结构**：上半部「一个局的一生」给人读——跟着一个真实的局从组到散走一遍，每步身后挂着规则号〔局n / 现n / 账n〕；下半部「规则总表」给实现与机器读——每号一行执法账（谁能按 / 何时能按 / 按下去改变什么）。**人从故事进、按号下钻；改守卫先改下半部对应行，表码不一致以码为准、当天回写。**
>
> 速记：全权 = 组织者 ∪ 管理员（权限只在单个球局内、散场即止）；到场 = 名册行且考勤 ok/late/join（absent/left 不算）。术语以 0 号文档为准。

# 上半部 · 一个局的一生

人物：老王（组织者）、阿珍和大李（正式球友）、小马（候补）、路人朋友们。

## 一、立局：从一句话到一个局

老王周二想约周四晚上的球。约球页点「+」，填时间（周四 19:00–21:00）、截止（默认开打前 2 小时，即 17:00）、场馆、人数（最少 4、最多 12）、规则三件、可见档。发出去，局是「报名中」，老王自己占第 1 坑。〔局1〕

球友们怎么看到它：选「任何人」人人可见；选「跟我打过」只有同场打过的人可见；选「仅邀请」列表里藏起来——但不管哪档，**拿到分享链接点开都能看能报，链接即门票**。被老王邀请的人点卡先弹加入卡。〔局1 可见性〕

人不够，老王去翻意向簿挑人：看谁想打这个时段，点邀请，局直接出现在对方「我的局」里——点不点加入随他，点了才占坑。〔局12 意向、局10 邀请〕

阿珍报名，顺手带俩朋友：整行 3 人一起算坑。坑够，全员正式；坑不够，整行落候补，绝不拆散谁。〔局2〕

## 二、截止时刻：没有闹钟，谁先看谁判

周四 17:00 过了。**没有任何定时器**——第一个打开约球页的人（可能是阿珍自己）触发判定：够 4 人，名单锁定「成局」；不够 4 人且没锁必打，当场「已终止」，报名者今天还能看见灰字，明天收走。〔系① 懒判定〕

成局之后规矩翻转：**截止锁的是退出，不是进入**——阿珍退不了了（防鸽），但新球友照常能报，一直开到局结束。〔局3〕

死局分支：人数不够死了，老王开打前还能救——点「恢复」进「待处置」，这个状态只有他看得见，其他人眼里局早就终止了。待处置两个出口：锁必打（救活成局）或撤局（安乐死）。〔局9、系② 观察者差异〕

撤局分支：开打前的三个在办状态（报名中/成局/待处置）老王都能撤，二次确认，订过场的提醒一句「记得去场馆退订」。撤完，他自己列表里这局永远消失。〔局8〕

## 三、变卦与必开（随时可能插进来）

老王订了场地：面板填 3 号、5 号场加总价——这局从此「必开」，人数不够也照打。不想订场也想必开？「锁定必打」空锁一声。〔局6、局5〕

老王改主意改时间地点：开打前随便改（截止时刻永远改不了）。但成局后动了时间或地点，名单自动解锁，大家获得一次退出权——改约不坑人。〔局4〕

## 四、开场：两本账握手的时刻

必开局的卡片变了：老王随时能点「开始打球」；阿珍大李要等到开打前 2 小时窗口开了才能点「进入现场」；**候补小马在 app 里永远没有这个按钮——他的唯一上路是到现场扫场地码**。〔现1 三道闸〕

19:00 整，谁都没提前开也不要紧：任何人点进现场，机器顺手把账开了——绝无死锁。〔现1〕

开账一刻，第二本账开张：场地片片待命，报名名单整队展开成名册——正式球友人人一行「未到」，阿珍带的俩朋友挂她名下当「访客」。〔现1 效果〕

开账后又有人线上报名？照收——局簿落报名，现场名册自动补一行。**单向：局簿流向现场，现场从不回头改局簿。**〔衔③〕

## 五、现场：人的状态，队的流动

阿珍到场，候场条点「我到了」：未到 → 到场，自动排进候场队尾；19:00 之后才点的记「迟到」，照样队尾，不许插队。〔现2〕

老王还没签到？**第一个签到的球友自动当临时管理员**，能发牌能结算，全场广播；老王来了随时收回。封管理员始终只有组织者能做。〔现2 首签、现14/现15〕

候补小马直接到场馆，扫场地码：入册、挂「空降」标、照摊钱、排队尾——线上名单纹丝不动。〔现3〕

阿珍的朋友里有个没报名的临时跟来：全权的人替他「带访客」，挂担保人名下，到场即排队。访客打球照打，积分不落账。〔现4〕

大李打一半有事先走：标「早退」——清出队列和场地，离场时刻落账，钱照摊。〔现2 left〕

## 六、打球：一场一场地转

候场队凑够人，队头几位自动上场——机器只认队头顺位，谁排前谁上，发牌算法在手机上算，总账只把关「必须是队头那拨」。〔现5〕

比分记在各自手机上：点分、撤回、长按清零，零联网零延迟——**机器不设守卫，这是故意的**。〔现6〕

这片打完，谁先点「上传」谁落账：战报、双轨积分（Elo 娱乐分 + DUPR 战力分）、人回流排下一场，一个事务要么全成要么全不成。阿珍和大李传的分不一样？先到的算数，后到的收一句「已按 X:Y 记账，有异议找组织者」。〔现7〕

传错了？组织者或管理员在这片**下一场落账之前**可以改分重落：账面改判、积分反算重加，但人已回流、场已排好，物理面不回头。〔现8〕

这场弃了：取消对局，人原样回队首，不计分不留战报；散场前还能一键全清。〔现9、现10〕

微调不断：换人任意到场者能点（留名广播）；歇一轮/想连战给自己随时点、给别人要全权；单双打、谁下、怎么配、连打上限，全权随时改。〔现11、现12、现13〕

## 七、收摊：一锤定音的三件事

21:00 老王点散场。还有在打的片？**先拦住**——逐片「上传定格」或「取消」，或一键全取消；残局不清完不放行。〔现16 残局闸、现10〕

散场确认一刻落三件事：

1. **这局从此「已结束」**——两本账共用的唯一终点。此后谁扫码进来、从哪点进来，都是只读回看，任何写动作拒收。〔衔②、系③〕
2. **考勤定格**——几点到、几点走、谁担保谁，全部定格，这是摊钱的依据。〔现16〕
3. **账当场出**——总价已定就算好人均（向下抹零，差额组织者兜底）；缺席的照摊、空降的照摊、候补不摊、访客的份归担保人。没定价的挂提醒等补填。〔现16、账2〕

事后补填：老王忘了填总价，账单页挂着提醒直达；补填完账单自动长出来，出账日期仍记散场那天。〔局11〕

## 八、事后：钱两清，局长存

回看：战报、考勤（考勤时刻分权可见）随时翻，分享链接任何人能看，含没登录的。〔系③〕

钱：阿珍微信转了，点「结算」；老王点「已收」。两时刻各记各的，双向灰字互相看得见，二次确认后都不可逆。〔账1、账2〕

老王的历史里这局永久可看；阿珍「累计打了 N 场」+1。

## 一生总览（状态轨迹）

```
正常线：报名中 →〔截止·懒判〕成局 →〔开账〕现场运转 →〔散场〕已结束
岔路①：报名中 →〔截止·懒判〕已终止 →〔恢复〕待处置(仅组织者可见) → 锁必打→成局 / 撤局→已撤
岔路②：开打前任意在办态 → 撤局 → 已撤（组织者不留痕）
显示口径：成局到点未开账显示"打球中"（纸面）、到点未散场显示"已结束"（其实没散）
——显示与真值的全部差异，见下半部「两套词汇」。
```

# 下半部 · 规则总表（执法账）

## 0. 两套词汇 + 三条系统规则

**两套词汇（防误读的第一课）**

| 词汇 | 是什么 | 谁在用 |
|---|---|---|
| 显示态（派生 7 态） | open / locked / live / done / pending / terminated / cancelled，由 `game_views.derive()` 按「存储 5 态 × 时刻 × ended_at」现算，live/done 不是存储态 | 只管给人看；**不作为任何写动作的判据** |
| 锚位旗（真值） | `live_opened`（LiveState 行存在）、`ended`（ended_at 非空）、`unlocked`（改约解锁窗内）、`forced`（订场 ∨ 手动锁） | 一切入口显隐、写窗、能力旗判据 |

**三条系统规则（所有行共同踩着）**

- **系① 懒判定**：截止无定时器，谁先读谁触发（`games._evaluate`）——过期 open 局当场判生死：够数 ∨ 必开 → locked；不够且非必开 → terminated。〔1.2 §4.8 · S14〕
- **系② 观察者差异**：pending 只组织者可见，其余人按 terminated 出（`masked`）——状态机的答案取决于问谁。〔1.2 §4.9〕
- **系③ 散场只读**：ended 之后一切现场写拒 `live_ended`，现场页切只读回看。〔2.3 §4.10 · S39〕

## 4. 衔接（两台机器的握手）

- **衔① 开账即桥**：LiveState 行存在 = 现场机开张；局簿 state 可仍是 open（必开不等截止）——两本账允许暂时各说各话，散场时对齐。
- **衔② 散场即锚**：ended_at 落 games 行，两本账唯一终态锚（批 1 裁定不存双真值）；散过的局不回头。
- **衔③ 单向补册**：join 落 formal 且账已开 → absorb_join 补名册行；现场从不回手改局簿。
- **衔④ 兜底翻 locked**：open 局提前开账再散场，散场时 state 翻 locked，否则派生永不到 done。
- **衔⑤ 吸收态口径**：到点未散场显示 done 但 ended=false、live_opened=true——入口与写窗全锚旗不锚显示态（2026-10-08 债清偿教训所在）。

## 5. 已知口径债（表已立、账未清）

1. **done 双义**：显示层 done cover 真终态与到点未散场两义（本表以锚位旗口径规避，显示层未清）。
2. **纸面 live**：locked 到点没人开账，显示仍是 live——机器知道真相（live_opened=false），用户看到的不是。
3. **两小时窗/必开判定前后端物理两份**：后端 `live.py _start_gate` 与前端 `format.ts cardLiveEntry` 注释互指同源、实为两份拷贝。**轻引擎代码化第一刀**：前端改吃后端定值（forced 已在发、入口态可加）。
