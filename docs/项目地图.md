正式语义条目（人维护）：
- **app/main.py** — FastAPI 后端入口：仅基建路由与 CORS，不装业务 ｜ 职责: 管应用装配、服务信息与 /api/health；不管业务 API（账号/球局按规格另建路由模块） ｜ 相关: 后端入口 健康检查 CORS 新增路由 ｜ 依据: app = FastAPI(title="mieball API") + CORSMiddleware(allow_origins=["*"])，仅 root() 与 @app.get("/api/health") 两个路由 ｜ @8dc793f
- **src/api/index.ts** — 前端数据层统一出口：转发 types/mock 并提供 delay ｜ 职责: 管「stores/页面一律从此取数」的出口约定与模拟延时；不管类型定义与 mock 数据本体（在 ./types、./mock） ｜ 相关: 取数出口 模拟延时 delay 接真后端 ｜ 依据: export * from './types'; export * from './mock'; export function delay(ms = 3000): Promise<void> ｜ @8dc793f
- **src/api/mock.ts** — 极薄数据源层：原样转出 mock/data 可变引用 ｜ 相关: mock 数据源 换真后端 数据引用 ｜ 依据: 仅一行 export { U, games, intents, ledger, myIntent, slots } from '../mock/data' ｜ @8dc793f
- **src/api/types.ts** — 全站核心类型定义：User/Game/LiveState/SheetPayload 等（24 处依赖，最核心契约文件） ｜ 相关: 类型定义 数据结构 字段语义 新增类型 ｜ 依据: export interface User/Game/LiveState/SheetPayload/WinData/PublishInput 等，带 alpha 行号语义注释；grep 实测 24 个文件 import '@/api/types' ｜ @8dc793f
- **src/main.ts** — uni-app 前端入口：创建 SSR app 并挂载 Pinia ｜ 职责: 管应用启动装配（createSSRApp + createPinia）；不管页面路由与业务逻辑 ｜ 相关: 应用入口 Pinia 挂载 启动流程 ｜ 依据: export function createApp() { const app = createSSRApp(App); app.use(createPinia()); return { app }; } ｜ @8dc793f
- **src/mock/data.ts** — 种子 mock 数据：13 名球员、7 个球局、意向与账本 ｜ 相关: 种子数据 球员名单 初始球局 改数据口径 ｜ 依据: export const U: Record<string, User>（含 me/wang/zha shadow 访客）、export const games: Game[]（id 101-107）、slots/myIntent/intents/ledger，全部可变引用导出 ｜ @8dc793f
- **src/stores/game.ts** — 球局 Pinia store：加入/退出/发布/截止/意向动作 ｜ 职责: 管球局与意向的状态变更及 toast 文案；不管路由跳转、不调 uni.*、不管现场记分（归 live store） ｜ 相关: 球局动作 加入退出 发布改局 留意向 ｜ 依据: export const useGameStore = defineStore('game', () => {...})，导出 joinGame/quitGame/publishGame/hitDeadline/inviteUser/shareGame/saveIntent 等，注释明令「不直接调 uni.*」 ｜ @8dc793f
- **src/stores/live.ts** — 现场 Pinia store：开局/签到/记分/收局结算 ｜ 职责: 管进行中现场 live 状态与 Elo 结算落账（写回 roster）；不管发牌/记分算法（utils/rotate、score 纯函数）与 uni.* ｜ 相关: 现场开局 签到 记分结算 Elo落账 ｜ 依据: export const useLiveStore = defineStore('live', ...)，startLive 展开 bring 为随行访客，endMatch 调 settleElo 并 p.elo = elo 落回同一批对象 ｜ @8dc793f
- **src/stores/ui.ts** — 全局 UI Pinia store：toast/弹层/胜利卡/撒花/分制 ｜ 职责: 管全局 UI 状态（sheet/toastMsg/win/confetti/scoreMode）；不管渲染（SheetHost/AppToast/WinPopup 组件负责）与 uni.* ｜ 相关: 弹层 toast 胜利结算卡 撒花 分制切换 ｜ 依据: export const useUiStore = defineStore('ui', ...)，导出 openSheet/closeSheet/toast/setScoreMode/showWin/closeWin/burst，scoreMode 默认 'elo' ｜ @8dc793f
- **src/stores/user.ts** — 用户 Pinia store：findUser/喜欢/换装，另导出换装部件常量 ｜ 职责: 管用户查询（现场名册优先）、liked 标记与换装状态；不管头像 SVG 生成（归 utils/chibi） ｜ 相关: 查用户 喜欢 换装 部件常量 ｜ 依据: export const useUserStore = defineStore('user', ...) 含 findUser/toggleLike/cyclePart，另 export const DRESS_PARTS / type DressPart / PART_NAMES ｜ @8dc793f
- **src/utils/chibi.ts** — Q 版头像 SVG 生成器：色表常量 + chibi() 拼接 ｜ 相关: 头像SVG 部件配色 ChibiAvatar 越界取模 ｜ 依据: export const chibi = (c?: ChibiConfig | null, s = 56): string 拼 SVG；export SKIN(4色)/HAIRC(6色)/SHIRT(8色)，索引 % 取模防越界 ｜ @8dc793f
- **src/utils/elo.ts** — 分数体系纯函数：Elo 结算引擎 + NTRP 分级 + 段位展示 ｜ 相关: Elo结算 NTRP分级 段位徽章 分数展示 ｜ 依据: export settleElo(winners, losers): EloOutcome[]（K=24、地板 400、shadow 半权重、无副作用落账在外）；另有 Tier/ntrp/fmtScore/tier/TIER_BG/TIER_FG ｜ @8dc793f
- **src/utils/format.ts** — 球局口径工具：人头/剩坑/摊费/我的局/熟人等纯函数 ｜ 相关: 人数口径 费用摊派 我的局 熟人判断 ｜ 依据: export const heads/needOf/perHead/myEntry/isOrg/isMine/known/slotName/freqName/slotBig；knownIds 基于 mock games 模块加载时算一次 ｜ @8dc793f
- **src/utils/rotate.ts** — 发牌引擎纯函数：找玩家/可上场队列/补片发牌/开下一场 ｜ 相关: 发牌排场 候补队列 胜者留场 均衡配对 ｜ 依据: export function pById/avail/fillCourts/nextMatch，均以 LiveState 为参数原地更新；fillCourts 含 winner 留场、balance 蛇形、cap>=12 三片逻辑 ｜ @8dc793f
- **src/utils/score.ts** — 记分纯函数：收局判定与误记撤分 ｜ 相关: 收局判定 撤销得分 净胜2 ｜ 依据: export function shouldEnd(sa, sb, target) 判「先到 N 且净胜 2」；undoScore 按 last 方回退并注明保留 alpha 的 else-if quirk ｜ @8dc793f
- **src/utils/time.ts** — 时间纯函数：中文开球时间解析与倒计时文案 ｜ 相关: 时间解析 倒计时文案 周几顺延 ｜ 依据: export function gameTime(t) 把「今晚 19:00/下周三 20:00」解析为 Date（今天的周X已过顺延下周）；untilTxt 返回「N 分钟/小时/天」或 null ｜ @8dc793f
