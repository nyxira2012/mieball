## 0. 一句话

同一场结束对局、一个事务，落两本账：**DUPR 积分**（核心战力数，慢而稳，管配平与榜单）＋**积分**（Elo 娱乐轨，快而爽，管情绪反馈）。

## 1. 双轨定位

| | DUPR 积分（核心轨） | 积分（Elo 娱乐轨） |
|---|---|---|
| 定位 | 权威水平值，变化慢、稳健 | 情绪价值，变化快、人人有爽点 |
| 形态 | 2.0–8.0，三位小数（如 3.52）＋可信度标记 | 整数（如 1247） |
| 消费方 | 均衡配对、战力榜、段位徽章、名片主数字 | 结束对局弹窗 ±预览、撒花、战力页娱乐视图（~~月度涨跌~~ → 落账改本月净胜场，见 §9.2 偏差 6） |
| 写入方 | 结束对局动作（唯一入口，双写之一） | 同上 |

## 2. 核心轨：DUPR 积分（口径）

- **复刻声明**：DUPR 公式不开源，业内复刻皆近似。本项目采纳其**口径**而非公式——队伍均值 / 分差权重 / 滚动窗口 / 可信度门槛 / 一场出道——底层引擎为 Elo 变体。不承诺与 DUPR 官方分对得上。
- **量表**：2.0–8.0 三位小数；段位徽章按 2.5 / 3.0 / 3.5 / 4.0+ 档映射（展示细节归 4.1 修订）。
- **队伍分 = 两人均值**，以此算期望——不被弱搭档单方面拖死。
- **分差计入权重**：11:2 与 11:9 对分数影响不同（每场对局都有比分，原料现成）。
- **滚动窗口：近 30 场**（DUPR 原版双打 60 场砍半——按群内场次密度适配），只认确认制结束对局。
- **存明细、派生分数**：每场存四人分数/比分/时间的事实明细，分数 = 窗口内明细的派生值，每次结算后对涉事注册球员重算。窗口调参、规则修正、人工纠偏都不用迁移数据，重算天然幂等。
- **不采纳**：单双打分开（本项目纯双打）；极端压缩/热门通缩（全球防刷机制，群规模用不上）。

## 3. 娱乐轨：积分（Elo）

- 引擎沿用现行实现（services/live.py 私有镜像 ↔ utils/elo.ts 对算），K=24 等其余常量不动。
- **参数变更（推翻 2.3 的「新人初始 1500 单一源」）**：**初始 1200、地板 800**。理由：双轨后 Elo 只担娱乐职能，重新调参收窄波动区间。迁移点四处：EloRating 默认值、services/live.py 镜像常量、utils/elo.ts、scripts/seed_demo.py 底数；存量账号分数不迁移，低于 800 者下次结算自然抬到地板。
- 从此不驱动任何严肃消费（配平/榜单/段位全部改吃 DUPR 积分）。

## 4. 访客口径（两轨统一）

- **进场**：访客参与的对局，注册球员两轨照算。
- **没特异性**：访客无档案、无身份、分数恒定不落账——DUPR 轨恒为标准得分（~~建议 3.0 = 自评默认档~~ → **2.5 = 与注册起步分同源**，2026-10-09 修订见 §10）；Elo 轨恒为 1200。
- **永远不变**指会话内也不动：访客就是一个恒定标准对手，不存在"访客打疯了分数上去"；「看不出是谁」——展示只有组织者给的称呼与随机小人。

## 6. 消费矩阵（谁吃哪个数）

- 均衡配对（轮换方式「怎么配」）→ **DUPR 积分**（未定级吃当前派生分，2.5 起）
- 战力榜排序、段位徽章、名片主数字 → **DUPR 积分**
- 结束对局弹窗 ±预览、撒花、战力页 Elo 娱乐视图 → **Elo 积分**（~~月度涨跌~~ → 2026-10-10 落账改本月净胜场，见 §9.2 偏差 6）
- 场次、胜负、last5、本月净胜场（`dupr_month_net`）→ 中性事实，不属任何一轨
- 榜单门槛：满 5 场入榜（= 定级门槛）；不足者标「参考」不参与排名

## 9. 实现归档（2026-10-08）

### 9.1 行为勾验（怎么操作、看到什么算过）

- **同一场球落两本账**：现场确认一场比分后，这一场同时记进 DUPR（明细+派生分）和积分 Elo（±涨跌）——战报回看里的 ± 就是 Elo 那本；DUPR 那本安静地进档案主数字与配平依据。
- ~~**建号自评五档**：建号卡上有「你大概什么水平」五档胶囊（2.0 刚上手 / 2.5 会一点 / 3.0 中等 / 3.5 进阶 / 4.0+ 高手），默认选中中等；选了别的档，起步分就从那一档起算。~~ → **2026-10-09 修订废除**：建号卡不再问水平，所有新号统一 2.5 起步。
- **满 5 场定级**：战力页榜单只排满 5 场的球友；不满 5 场的在「参考 · 未定级」区，没有名次、标「未定级」小签，页面上写着「满 5 场自动入榜」。
- **主数字全换 DUPR**：我的页、战力卡、他人档案、榜单行、现场小字，显示的都是 2.0–8.0 三位小数的 DUPR 分加段位档（2.0 / 2.5 / 3.0 / 3.5 / 4.0+）；~~月度涨跌仍记积分（Elo）~~（2026-10-10 落账改记本月净胜场，见 §9.2 偏差 6）。
- **均衡配对看 DUPR**：现场开「均衡配对」时，强弱搭配按 DUPR 分排——没打过的球友按起步 2.5 代位（原自评档，2026-10-09 修订废除），访客恒 2.5。
- **Elo 参数**：积分（Elo）初始 1200、最低 800；低于 800 的存量分数不用管，下次结算自然抬回 800。
- **访客两轨恒定**：访客打得多好多差都不记分——DUPR 恒按 2.5 代入（原 3.0，2026-10-09 修订）、Elo 恒按 1200 代入，只算陪练不计账。

### 9.2 实现偏差（动了设计的什么、为什么、谁裁决）

1. **访客 DUPR 标准分落 3.0**（§8 遗留暂定项）：按规格建议值落定，与自评默认档同源。裁决：技术设计按规格建议值拍板，静默运行留痕。（2026-10-09 修订：随自评废除改 2.5，见 §10）
2. **「未定级以自评档代位」的配对口径细化为「吃当前派生分」**：起步分就是自评档，打 1–4 场期间派生分连续演进，第 5 场定级无切换跳变——若按字面「未定级回自评档」，第 5 场配对会突变。裁决：技术设计拍板（规格语义的细化，非推翻）。（2026-10-09 修订：口径存活，锚点改统一 2.5）
3. **Elo 初始分迁移点是五处不是四处**：规格 §3 列了四处，实现发现轮换算法里还有第五处 1500（均衡排序初始分）——随均衡配对换源 DUPR 整体退役，未迁移 1200。裁决：技术设计拍板（换源后该常量失去职责）。
4. **前端「Elo/NTRP 分制切换」退役**：主数字只有 DUPR 一态（§6 消费矩阵），旧五档展示制（SS/S/A/B/C 与 NTRP 换算）随换源失去消费方，整套删除；段位档名 2.5/3.0/3.5/4.0+（<2.5 显 2.0）。裁决：技术设计拍板，展示细节样式归 4.1 修订。（2026-10-12 修订：胶囊换 DUPR/Elo 新对复活——榜单排序正式口径仍只 DUPR，Elo 是前端娱乐视图，见 §11）
5. **DUPR 引擎参数**（规格 §2「Elo 变体」口径内的落地值）：分差尺度 2.0 档、未定级快涨（K=0.25）已定级慢稳（K=0.10）、分差权重 0.7–1.3、量表钳制 2.0–8.0；派生分只在后端算（前端纯展示，无第二真值）。裁决：技术设计拍板。
6. **月度涨跌与战力榜仍走演示数据**：两者后端化（月度 Elo 涨跌落账、榜单端点）规格 §8 未列本域落点，留 4.1 修订接真。（2026-10-10 落账：**榜单端点已实现**——GET /api/stats/leaderboard，可匿名、裸数组、DUPR 降序同分 id 升序、行=账号身份四件+card 六件、0 场新号在列、注销不列；前端战力页/档案卡已切真，mock 榜单退役。**月度涨跌**随 card 的 dupr_month_net 一并出真值（本月净胜场口径）；Elo 娱乐轨的涨跌落账维持 2.3 结算链，不另设端点。）（2026-10-12 修订：行增发 `elo_rating` 一件，见 §11）

## 10. 修订记录

### 2026-10-09 · 自评五档废除，统一 2.5 起步

- **裁决（用户拍板）**：建号自评是错误设计——注册卡多一栏摩擦、多数人瞎选、实际价值只有前几场（未定级快涨 K=0.25 本就把人快速收敛到真实水平），整链废除。
- **新口径**：注册球员与访客统一按 **2.5** 起步/代位——同源原则保留（无档案标准分与起步分是同一个数），推翻裁决 3 的 DUPR 3.0 与裁决 4 的自评五档。其余不动：满 5 场定级、窗口 30 场、未定级快涨慢稳双速、Elo 轨 1200。
- **实现随动**：后端删 `SELF_RATINGS`/`start_of`/`Account.self_rating` 列/`self_rating_invalid` 错误码/建号入参，`GUEST_DUPR` 3.0→2.5 兼任唯一起步锚；前端删建号卡「你大概什么水平」五档胶囊与 `self_rating` 协议字段，展示文案随迁。
- **存量**：自评档列删除后不再被读取，存量派生分在下次涉事结算重放时以 2.5 锚自然重算收敛。
