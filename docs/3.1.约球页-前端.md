# 3.1 约球页 — 前端

## 一、总纲

约球页干两件事：把局约起来，把下次的局攒出来。

0 号文档核心循环里"建局 → 报名"和"留意向 → 凑人订场"两段，主场都在这页。对着 0 号文档的问题清单，这页治三个毛病：接龙报名乱、订场靠赌、想固定打球的人凑不到一起。

页面三块功能是一条线，不是三个孤岛：**我的局**管约上的局，**找局打**管加入别人的局，**意向**管"我什么时候想打"。意向不是留言板——组局的人翻意向列表，看中谁就邀请谁，意向是下次局的种子。

本文档只定骨架。组局的细账——发局表单、局卡字段、人数范围、截止锁定、候补、费用摊法——见 3.2，以 3.2 为准。

## 二、核心功能

### 1. 我的局

我发起的、我加入的局都在这，一眼看到：时间、地点、谁加入了、还剩几坑。

- 组织者：发局，定时间、地点、人数（细账见 3.2）；发局后和参加的人一样查看时间地点、名单等信息；能改信息；能取消局。
- 参加的人：点进局看名单和每个人带了几人；不想去了能退出。
- 别人邀请我的局也出现在这，点一下就加入。

### 2. 找局打

翻别人发的局，卡片上就是时间、地点、还剩几坑。看中哪个点加入，可以带人（带的人也占坑）。不想去了就退出。

### 3. 意向

留自己的打球意向：大概什么时段想打、多久打一次。也能翻别人的意向。

组局的人看中谁，点邀请，这个局就出现在对方的"我的局"里。

## 三、辅助功能

- **筛选**：找局打里按时间、地点筛，快速找到能打的局。（帮：找局打）
- **分享**：局上的一个小按钮，把局转到微信群里拉人。（帮：找局打、我的局）
- **改意向**：随时改、删自己的意向。（帮：意向）
意向切换显示所有人意向和熟人意向
意向排序优先显示喜欢的人和熟人意向
意向卡片上显示此人的意向内容和分值，点击后显示此人档案卡

## 四、页面设计

**约球页（主页）**
- 头部大标题+日期行
- 跑马灯，显示被邀请情况，距离最近参加的球局时间
- 球局标题（悬浮置顶）、折叠筛选项和列表：竖排游戏卡——时间大字 + 局名 + 地点 + 最少/最多人数（局卡口径以 3.2 为准），如果有我参加/组织球局置顶
- 意向标题（悬浮置底）、折叠筛选项和列表：竖排游戏卡，默认显示熟人意向，排序优先显示喜欢的人
- 右下角"+"按钮：发局（填时间、地点、人数、预计费用、规则等）

**子页面**

- 局详情页：从我的局或找局打点进去。局信息、名单、加入/退出按钮；组织者看到的是管理操作——改信息、取消局、加场、必定开局（见 3.2）。

**抽屉**

- 意向抽屉：点击意向内人物卡片后显示此人档案卡

**弹窗**

- 带人：点加入时选带几个人
- 退出局 / 取消局的确认
- 留意向、改意向的小表单

## 五、用户故事（当验收用）

写完拿这三个故事走一遍，每一步都得有地方落：

1. **老王发局**：周六想打球 → 点发局（周六上午、阳光球馆、8 人）→ 点分享小按钮转到微信群 → 球友点进来加入，小刘带了 1 人，还剩几坑跟着变 → 周六开打。
2. **小李找局**：临时想打 → 找局打翻一圈，筛今晚 → 看中一个，加入时带上朋友（占 2 个坑）→ 局进了"我的局" → 临时有事，点退出。
3. **小张攒局**：固定想打周三晚 → 留意向 → 老王组周三的局，翻意向列表看到小张 → 点邀请 → 局出现在小张的"我的局"里 → 点一下加入。

三个故事走通，这页就成了。
