# 3.2 组局 — 前端

## 一、总纲

组局干两件事：把局设出来，把设好的局亮出去给参加者报名，给组织者管理。

页面三块是一条线，不是三个孤岛：**创建组局**管填什么发出去，**局卡片**管局在约球页列表上长什么样，**组局详情**管点进去之后的报名和管理。发局的人叫组织者（0 号术语），只管自己的局，自己就算第 1 个人、在名单里。

本文档管到"局约成"为止：截止、名单锁定；到点后的签到、轮转、记分是打球页（2.1）的事。人数口径全篇统一用**满员线**——进度只讲"还剩几坑"；最少人数只干一件事：截止时判局成不成。

## 二、核心功能

### 1. 创建组局

发局就一张表，从上到下填完点发布（2026-10-04 改版：整表瘦身、拨盘选准，无费用无说明）：

- **局名**：可不填。输入框占位直接显示自动名（时间 · 地点，随所选时间/场地联动），不填发布时用它。
- **时间**：日期（今天/明天/后天/具体日+周几，往后 14 天）+ 24 小时制起止时刻，拨盘直选，30 分钟一格；默认两天后 19:00–21:00。"打多久"由起止时刻算出，不再单独填。
- **组局截止时间**：拨盘直选一个准确时刻。默认自动 = 开打前 2 小时（改开打时间它跟着重算）；手动拨过即固定、可一键回自动；可拨范围限死在"现在之后、开打之前"。到点名单锁定，参加者不能再退出；此时低于最少人数，局自动终止（组织者可恢复，或提前"锁定必打/订场登记"免除，见组局详情）。截止时间发布后定死不能改，不做延期。
- **地点**：球馆名 + 地址。
- **人数**：最少人数 + 最多人数（满员线）。不足最少：截止时自动终止；到达最多：后来者进候补。
- **规则**（2026-10-04 定：原"说明"字段去掉，改规则三件直选，落局的规则数据）：**分制**（11/15/21，先到 N 且净胜 2）、**轮转方式**（均衡配对/赢家留场/纯粹轮转）、**得分规则**（每球得分制/发球得分制）。
- **费用与说明不进表单**（2026-10-04 定）：新发局费用未定，详情/报名弹层显示"费用未定"；存量局的费用与说明保留并照常显示。现场 AA，以后要做钱再回表单。

### 2. 局卡片

局发出去，以局卡回到约球页列表：

- **卡面**：时间大字 + 局名 + 地点 + 人数范围 + 状态（进行中 / 满员候补 / 剩几坑）。局名行右上挂参加者头像叠层（前 5 个，超出显示 +N，有随行标"·含随行"）；卡面右下是角色标识（我发起 / 被邀请 / 已加入，没有就不显示）。已订场的局卡面加一枚小标「已订场 · 必开」（仅手动锁则「必开」），卡面不放场地号和钱，保持干净（2026-10-04 订场改版）。
- **费用不在卡面**：卡上不放人均——有费用的局，总价和人均进局详情看，点加入时报名弹层报人均约数；新发局费用未定，报名弹层显示"费用未定"。（2026-10-04 用户定：去掉卡上的"人均 ¥N"标识；同日定：费用退出发局表单。）
- **置顶**：我发的、我参加的局排最前。
- **入口**：点局卡进组局详情。

### 3. 组局详情（加入/管理）

参加的人和组织者点的是同一张局卡、进同一份局详情，信息一样，就差组织者那排管理按钮。

- **局信息**：时间、地点、场地（已订场亮场地号，如「3号、5号」，没订显示「待定」——到场馆照号找场）、人数进度（如 5/8，还剩几坑）、规则牌（分制+得分规则+轮转方式，"迟到排队尾"仅存量局显示）。费用仅存量局有：显示总价/人均（不足最少按最少摊，够最少后按当前人数摊）；新发局显示"费用未定"，订场登记后落定为总价+人均（按当前人数摊，最少保底作废）。说明仅存量局有。
- **名单**：组织者排在名单头一个（占 1 坑），往下谁报了、每人带了几人；满了之后加入的进名单下方单独的**候补栏**。组织者另有邀请按钮，可把意向列表（3.1）里的人拉进局。
- **加入/退出**（参加者）：没加入的人=加入（可带人，带的也占坑；满了就进候补）；加入了的人=退出（截止前）。
- **管理**（组织者）：组织者没有加入/退出按钮，看到的是下面这排——
  - **改局**：时间、地点、人数范围、规则三件都能改，名单不动；名单里的人再打开，看到的就是新信息。上限放宽（原"加场"）也走这里：上限提高后候补按先后自动转正，转完仍超出，超出的候补者看到"满员，建议下次再参加"（2026-10-04 订场改版：加场按钮取消，上限与场地号解耦，加片订场去「锁定必打」面板添号）。
  - **锁定必打 · 订场登记**（三态一入口，2026-10-04 订场改版）：订场发生在 app 外（场馆现场/订场平台），app 只登记结果。点开面板填两栏——场地号（几片填几个号，顿号/逗号/空格隔开，输入框下实时显示"识别到 N 片"；片数不单独填，就是号的个数）、总价（照订场小票手填，免费场填 0，面板实时显示人均）。三种状态：
    - 没锁：「锁定必打 · 可登记订场」——按最少人数在截止时判成不成（照旧）；
    - 空锁：「已锁定必打 · 去登记场地」——不登记场地只上手动锁，人不够最少也照打（原"必定开局"行为，免费场/老友局用）；
    - 订场锁：「已订场 · 3号、5号 · ¥480」——填了保存即订场锁，不用再点一次锁定：这局必开、费用落定（总价+人均，最少保底作废）、场地号亮给参加者（局卡小标 + 详情场地栏）。
    - 面板随时可重开改登记：临期退一片就删一个号、总价改成退完后实际花的钱，人均跟着重算；场地全退光可「清空登记」——局回到未订场原样（费用回"未定"、截止照常判人数），但手动锁是组织者明确点的，不跟着松。**必打 = 手动点过 或 场上有号**，一个判定管到底。截止后（名单已锁）面板仍可改——临到场场馆换号很常见，锁名单只锁人。发局表单不加订场入口，先订场的人发完局点一下这个锁就登记上了。
  - **撤局**：取消局要过确认；局从约球页撤下，报名的人"我的局"里同步消失。已订场的局，确认框里提醒一句"记得去场馆退订"。
  - **恢复**：自动终止的局，对外同撤局一样消失；组织者的"我的局"里留一条"未成局"记录，点恢复，一切回到终止前的状态——名单原样，再决定锁定必打还是撤局（已订场的局必打，走不到自动终止，此路只属未订场局）。

## 三、辅助功能

- **分享**：局详情上的小按钮，把局转到微信群拉人。（帮：局详情）
- **邀请**：发完局翻意向列表（3.1），看中谁点邀请，局直接出现在对方的"我的局"里，提示有人邀请；局详情名单区的邀请按钮干的是同一件事。（帮：局详情）

## 四、页面设计

**发局表单**（约球页右下角"+"唤起，向上弹出抽屉；2026-10-04 改版）
- 局名（占位即自动名）/ 开打（日期 + 起止时刻拨盘，30 分钟一格）/ 组局截止（拨盘 + 自动跟随标记）/ 地点 / 人数（最少—最多）/ 规则三件（分制、轮转、得分规则），从上到下一屏填完
- 底部一个"发布"按钮；改局复用同一表单带出原值（截止只读）

**局卡**（长在约球页列表里，位置和排法见 3.1）

**局详情页（子页面）**
- 头部局信息卡：时间大字、地点、场地（已订场亮号/待定）、人数进度 + 剩几坑、总价 + 人均、说明，挂分享小按钮
- 名单区：参加者（组织者在列）+ 候补栏；组织者的邀请按钮
- 底部按钮：加入（满了进候补）/ 退出（截止前）；组织者替换成改信息、取消局；锁定必打·订场登记（三态一入口）挂在底部动作区

**弹窗**
- 带人：点加入时选带几个
- 候补提示：满员后点加入，提示将进入候补
- 退出局 / 取消局的确认（取消已订场的局，确认框带退订提醒）
- 改信息：复用发局表单，带出原值改完保存（上限放宽后候补自动转正）
- 订场登记：锁定必打面板——场地号（实时识别 N 片）+ 总价（实时人均），保存即订场锁；空填锁定即空锁；已订场可重开改登记或清空（2026-10-04 订场改版）

## 五、用户故事（当验收用）

> 2026-10-04 起：费用不再进发局表单。故事 2/3 的人均摊法按"有费用的局"（存量口径）验证，新发局费用未定、不显示摊法。

写完拿这三个故事走一遍，每一步都得有地方落：

1. **老王发局**：周六想打球 → 约球页点"+" → 拨：后天上午 9 点打 2 小时（起止拨盘）、阳光球馆、4-6 人、11 分制 → 发布 → 局卡置顶上列表（时间地点 + 4-6 人）→ 名单头一个就是老王自己 → 点分享转微信群拉人。
2. **小刘入局**：群里点进局卡 → 局详情：名单 3 人（不足最少 4，人均按最少摊 75）→ 带朋友加入，5 人，人均变 60 → 第 6 人加入，6/6 满、剩 0 坑 → 小陈再点加入，进候补栏 → 老王点加场，上限提到 8 → 小陈自动转参加，7/8、剩 1 坑。
3. **老王救局**：到截止还只有 3 人，低于最少 4 → 局自动终止：列表撤下、报名者"我的局"里消失 → 老王"我的局"里留着"未成局"，点恢复，名单 3 人原样回来 → 点锁定必打：最少人数作废、不再自动终止 → 局照开，人均 300 ÷ 3 = 100。
4. **老王订场**（2026-10-04 订场改版）：周六局报名 7 人（上限 8），费用一直"未定" → 周五老王去球馆订了 2 片，回来点局详情的锁，填「3号、5号」和总价 480 → 按钮变「已订场 · 3号、5号 · ¥480」，人均 480 ÷ 7 ≈ 69，参加者局卡亮「已订场 · 必开」、详情场地栏亮号 → 周六到场馆照号找场。若临期只有 5 人，退掉一片：重开面板删「5号」、总价改 260 → 剩 3号，人均 52，局照样必开。

三个故事走通，组局这摊就成了；第四个走通，订场这条线就接上了。
