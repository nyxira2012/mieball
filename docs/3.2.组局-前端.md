# 3.2 组局 — 前端

## 一、总纲

组局干两件事：把局设出来，把设好的局亮出去给参加者报名，给组织者管理。

页面三块是一条线，不是三个孤岛：**创建组局**管填什么发出去，**局卡片**管局在约球页列表上长什么样，**组局详情**管点进去之后的报名和管理。发局的人叫组织者（0 号术语），只管自己的局，自己就算第 1 个人、在名单里。

本文档管到"局约成"为止：截止、名单锁定；到点后的签到、轮转、记分是打球页（2.1）的事。人数口径全篇统一用**满员线**——进度只讲"还剩几坑"；最少人数只干一件事：截止时判局成不成。

## 二、核心功能

### 1. 创建组局

发局就一张表，从上到下填完点发布：

- **局名**：可不填，默认用"时间 + 地点"自动起（如"周六上午 · 阳光球馆"）。
- **时间**：哪天、几点开打、打多久。
- **组局截止时间**：到点名单锁定，参加者不能再退出；此时低于最少人数，局自动终止（组织者可恢复，或提前点"必定开局"免除，见组局详情）。截止时间定死不能改，不做延期。
- **地点**：球馆名 + 地址。
- **人数**：最少人数 + 最多人数（满员线）。不足最少：截止时自动终止；到达最多：后来者进候补。
- **预计费用**：填一个总价。人均不用自己算——局详情里自动摊：人数不足最少按最少摊，够最少后按当前人数摊。
- **说明**：这局什么打法——水平要求等。

### 2. 局卡片

局发出去，以局卡回到约球页列表：

- **卡面**：时间大字 + 局名 + 地点 + 最少/最多人数。
- **置顶**：我发的、我参加的局排最前。
- **入口**：点局卡进组局详情。

### 3. 组局详情（加入/管理）

参加的人和组织者点的是同一张局卡、进同一份局详情，信息一样，就差组织者那排管理按钮。

- **局信息**：时间、地点、人数进度（如 5/8，还剩几坑）、总价、人均、说明。
- **名单**：组织者排在名单头一个（占 1 坑），往下谁报了、每人带了几人；满了之后加入的进名单下方单独的**候补栏**。组织者另有邀请按钮，可把意向列表（3.1）里的人拉进局。
- **加入/退出**（参加者）：没加入的人=加入（可带人，带的也占坑；满了就进候补）；加入了的人=退出（截止前）。
- **管理**（组织者）：组织者没有加入/退出按钮，看到的是下面这排——
  - **改局**：时间、地点、人数范围、费用、说明都能改，名单不动；名单里的人再打开，看到的就是新信息。
  - **加场**：候补人多，加一片场地，人数上限跟着提高，候补按先后自动转参加者；转完仍超出，超出的候补者看到"满员，建议下次再参加"。（加场的钱在改信息里把总价跟着改。）
  - **必定开局**：人不够最少也照打——点了之后，截止时不再因人数不足自动终止，最少人数要求作废。
  - **撤局**：取消局要过确认；局从约球页撤下，报名的人"我的局"里同步消失。
  - **恢复**：自动终止的局，对外同撤局一样消失；组织者的"我的局"里留一条"未成局"记录，点恢复，一切回到终止前的状态——名单原样，再决定必定开局还是撤局。

## 三、辅助功能

- **分享**：局详情上的小按钮，把局转到微信群拉人。（帮：局详情）
- **邀请**：发完局翻意向列表（3.1），看中谁点邀请，局直接出现在对方的"我的局"里，提示有人邀请；局详情名单区的邀请按钮干的是同一件事。（帮：局详情）

## 四、页面设计

**发局表单**（约球页右下角"+"唤起，向上弹出抽屉）
- 局名（默认时间 + 地点）/ 时间 / 截止时间 / 地点 / 人数（最少—最多）/ 预计费用（总价）/ 说明，从上到下一屏填完
- 底部一个"发布"按钮

**局卡**（长在约球页列表里，位置和排法见 3.1）

**局详情页（子页面）**
- 头部局信息卡：时间大字、地点、人数进度 + 剩几坑、总价 + 人均、说明，挂分享小按钮
- 名单区：参加者（组织者在列）+ 候补栏；组织者的邀请按钮、加场入口
- 底部按钮：加入（满了进候补）/ 退出（截止前）；组织者替换成改信息、取消局；必定开局挂在局信息卡上

**弹窗**
- 带人：点加入时选带几个
- 候补提示：满员后点加入，提示将进入候补
- 退出局 / 取消局的确认
- 改信息：复用发局表单，带出原值改完保存

## 五、用户故事（当验收用）

写完拿这三个故事走一遍，每一步都得有地方落：

1. **老王发局**：周六想打球 → 约球页点"+" → 填：周六上午 9 点打 2 小时、阳光球馆、4-6 人、场地费 300、说明"新手友好" → 发布 → 局卡置顶上列表（时间地点 + 4-6 人）→ 名单头一个就是老王自己 → 点分享转微信群拉人。
2. **小刘入局**：群里点进局卡 → 局详情：名单 3 人（不足最少 4，人均按最少摊 75）→ 带朋友加入，5 人，人均变 60 → 第 6 人加入，6/6 满、剩 0 坑 → 小陈再点加入，进候补栏 → 老王点加场，上限提到 8 → 小陈自动转参加，7/8、剩 1 坑。
3. **老王救局**：到截止还只有 3 人，低于最少 4 → 局自动终止：列表撤下、报名者"我的局"里消失 → 老王"我的局"里留着"未成局"，点恢复，名单 3 人原样回来 → 点必定开局：最少人数作废、不再自动终止 → 局照开，人均 300 ÷ 3 = 100。

三个故事走通，组局这摊就成了。
