## 1. 这是要解决什么问题（必填，人话）

- 轮换规矩只活在代码里：现行三种轮换法（赢家留场／纯粹轮转／均衡配对）没有一册定义各自怎么排，2.1、2.2 都引用它，但谁也说不清它的准数。
- 下场方式太少：真实球场常用的「一场只下一两个人」没有——人多出三两个时，整队换（纯粹轮转）太折腾、赢家留场又坐穿板凳。
- 选方式全凭经验：几片场、几个人、该用哪种轮换，组织者靠手感，新人组织者直接懵。
- 单打没有正经入口：卡头的「单打／双打」是按上场人数倒推显示的，不是选出来的。
- 现行引擎是串行的：一次只有一片在打、其余干等，与已裁定的多片并行（一片各打各的）不符（2.2 修订⑧）。
- 一句话成功画面：组织者打开规则抽屉，系统按片数和人数亮一个带理由的推荐，点一下就按最合适的方式轮转；每片各打各的，结束对局就排下一场，谁上谁下、和谁一边，规矩清清楚楚、人人可预期。

## 3. 用户故事（必填）

1. 作为组织者，我想按片数和签到人数拿到带一句理由的推荐，以便不用凭手感猜轮换方式。（§1 问题三）
2. 作为组织者，我想在人多个别几个时选「1人下／2人下／3人下」，以便等的人马上轮上、场上的人不至于整队被换。（§1 问题二）
3. 作为组织者，我想给赢家留场设连庄上限，以便赢家不把板凳坐穿。（§1 问题二）
4. 作为球友，我想每片各打各的、结束一场马上排下一场，以便多片时不用等别片打完才轮到。（§1 问题五）
5. 作为组织者，我想人少时一键全场改单打，以便铺不满片也能全员上场。（§1 问题四）
6. 作为球友，我想随时看到当前是什么轮换方式，以便自己什么时候上场、会不会被换心里有数。（§1 问题六）
7. 作为组织者，我想让上场的人强弱搭配着分边，以便两个高手不挤同一边、新手不被晾在弱队挨打。（§1 问题一）

## 4. 输入 / 输出场景（必填，文档核心）

> 前提统一：现场的一切记在同一本总账上，发牌与推荐都由总账算好定值，画面只呈现（2.2 已定好这条怎么算）。谁能改规则：组织者与管理员（2.2 已定，本册不重定义）。

### 场景 4.1：选轮换方式（全权者）
- **身份**：组织者或管理员
- **前提**：现场已点亮（有没有片在打都行）
- **操作**：从顶条赛制入口打开规则抽屉。分制选择（11/15/21）照旧留在抽屉里；轮换是四件事各选各的——
  1. **单打／双打**（全场统一，不一片一个样）
  2. **谁下**：单打两种（全上全下／输家下）；双打五种（全上全下／输家下／1人下／2人下／3人下）
  3. **怎么配**（仅双打有）：按候场队序／均衡配对
  4. **连庄上限**（仅输家下显示）：数字可改，默认 3；选 0 时旁边常驻一行「当前＝不限」
- **结果**：点选即生效；抽屉里当前推荐的那项亮「推荐」标签＋一句话理由（见 4.2）；球友打开同一抽屉是只读的，只看得到当前生效的选择，看不到推荐标签与理由
- **禁止**：一片单打一片双打混着打；球友改动任何一项（2.2 已定的权限）。

### 场景 4.2：推荐（自动，随人数片数变）
- **身份**：全场（无需操作）
- **前提**：现场已点亮；签到可打的人数或正在使用的片数发生任何变化
- **操作**：无——总账当场重算推荐
- **结果**：全权者下次打开抽屉看到的是最新推荐＋最新理由；推荐不弹窗、不打扰、不替人切。判断规则**从上往下、先命中为准**（「铺满」按当前单双打算：双打＝片数×4、单打＝片数×2）：

**打的是双打：**

| 情形（从上往下） | 推荐 | 一句话理由 |
|---|---|---|
| 连单打都铺不满（人数 < 片数×2） | 不荐 | 先等人（差人卡 2.1 已有） |
| 铺不满片、但人够把现有片按单打铺满 | 提示「改单打可全员上场」——**提示可点，点了即全场换单打** | 改了就能全员上场，不混格式 |
| 刚好铺满（＝片数×4） | 全上全下 | 人人每轮都在场上 |
| 多 1 人 | 1人下 | 等的人下一场马上轮进来 |
| 多 2 人 | 2人下 | 候场周转顺，连庄天然被拆 |
| 多 3 人 | 3人下 | 同上 |
| 多出 ≥ 一整片的人（≥铺满数＋4） | 全上全下 | 队伍长了，全下轮得最快最公平 |

**打的是单打：**

| 情形（从上往下） | 推荐 | 一句话理由 |
|---|---|---|
| 连一片都铺不满（人数 < 片数×2） | 不荐 | 先等人 |
| 刚好铺满（＝片数×2） | 全上全下 | 人人每轮都在场上 |
| 多 1 人 | 输家下 | 单打就两种，赢家留场最顺 |
| 多出 ≥ 一整片的人（≥铺满数＋2） | 全上全下 | 轮得最快最公平 |

- 发局时不再选轮换（2026-10-07 裁决：建局表单去掉模式选择、分制保留）——轮换从现场点亮起才有值：**自选前「谁下」一直跟最新推荐走；推荐为「不荐」时挂「全上全下」占位**（此时也无片开打）；组织者一旦自选，他的选择一直有效，推荐只亮标签不再替他改。
- 「怎么配」不进推荐，由组织者自定（默认按候场队序）；单双打默认双打。
- **禁止**：系统自动替人切换任何一项；推荐变成弹窗或强制。

### 场景 4.3：开场发牌，多片同时开赛（自动）
- **身份**：全场（无需操作）
- **前提**：现场已点亮，报到的人够开打（双打每片 4 人、单打每片 2 人；够几片开几片，片数以现场事实为准）
- **操作**：无——够人自动发牌上片（2.2 场景 4.1 已定）
- **结果**：每片同时开赛，各有各的记分板、各打各的比分；候场队按顺序供给各片（多片同时要人时，按片号先后取）；人不够的片显示「还差 N 人」（2.1 差人卡）
- **禁止**：一片等另一片打完才开（多片并行的规矩，2.2 修订⑧所定）。

### 场景 4.4：结束对局，各片各排各的（自动；各方式的行为真值）
- **身份**：全场（确认结束对局是全权者的活，2.2 已定；积分落账归 2.3《记分与散场》）
- **前提**：一片打完、全权者确认结束对局
- **操作**：无
- **结果**：按当前「谁下」处理这一片——
  - **坑补不满，本场就不下人**（各方式通用）：要腾的坑候场人数不够补时（输家下要 2 人、N人下要 N 人、全上全下要 4 人），本场谁也不下、**原班再战**；想换搭子换边，用点人换人里的「同片互换」（2.2 已有）
  - **全上全下**：场上所有人下场、按先后排候场队尾；这片由候场队首补满全新一队（怎么配在此生效，见 4.5）
  - **输家下**：赢的一队留场（连庄＋1，卡头连庄数跳动）；输的一队下、排队尾；候场队首补空位——双打补上来的两人成一队挑战，单打补一人
  - **1人下／2人下／3人下**：这片在场上待得最久的 N 人下、排队尾；候场队首逐个补进空位，**谁下补谁的坑**（留下的保住自己的半边，新来的顶空坑，不重新分队）
  - 「在场上待得最久」＝从上场起连续在场上的场数：下过场就清零，中途换上的人从换上那刻起算；**资历并列时**（比如开场第一场打完的四人）按当初上场的先后，先上的先下
  - 下场的人排候场队尾（先下的排前面）
- **禁止**：别片还在打时这片等着不发（各片独立）；补坑的人被重新分队（只有凑全新一队才分边）。

### 场景 4.5：均衡配对怎么分边（自动）
- **身份**：全场（无需操作）
- **前提**：怎么配＝均衡配对，且这片要凑**全新的一队**（开场发牌、全上全下补片、连庄到点补片）
- **操作**：无
- **结果**：这片的人按积分从强到弱排——**最强的和最弱的一队，第二和第三一队**（强配弱，不让两个高手挤同一边）；没打过的人（新人、访客）按初始分 1500 算（2026-10-07 定值，战力册将来沿用）；分一样按候场队先后；单打没有分队一说，选单打时「怎么配」不显示。怎么配＝按候场队序时，全新一队按队序分边：**第 1、2 位一队，第 3、4 位一队**。输家下时，均衡只在凑全新一队时生效（开场发牌、连庄到点补片）；日常补位的挑战两人按队序上来组一队，不重配
- **禁止**：均衡配对越过候场队序挑人——上场顺序永远是队序，均衡只管上了场怎么分边（不插队）。

### 场景 4.6：连庄到点（输家下专属，自动）
- **身份**：全场（无需操作）
- **前提**：谁下＝输家下；一队连赢场数到上限（默认 3）
- **操作**：无
- **结果**：到点这场照常结束对局、照常落账，但赢的一队**不再留场**——整队下、排队尾；这片由候场队首补满全新一队（此时怎么配生效）；连庄数在卡头显示（**新增显示**——现行产品没有连庄计数）
- 上限改了立即生效：当前连庄数已经到新上限的，这场打完就下
- **禁止**：全上全下与 1/2/3人下设连庄上限（前者无连庄，后者先上先下天然拆，入口也不显示）。

### 场景 4.7：打到一半换规矩（全权者）
- **身份**：组织者或管理员
- **前提**：有片正在打
- **操作**：在规则抽屉里换「单双打／谁下／怎么配／连庄上限」任何一项
- **结果**：在打的对局**照旧打完**（比分、积分不受任何影响）；下一场起按新规矩发牌。四个衔接的规矩：
  1. 从输家下切到别的方式：原留场的人这场打完按新方式处理（全上全下就一起下，N人下按资历算——他们的资历从上场起照算）
  2. 切到输家下：现在场上的人连庄数清零重算（他们不是赢上来的）
  3. 换单双打（两个方向同一条）：这片打完后场上的人**全下、按新格式凑全新一队**（双打切单打补 2 人、单打切双打补 4 人，怎么配在新一队上生效）；多片时先结束的片先按新格式开赛、慢片还在打旧格式，几分钟过渡属正常，以各自下一场为准
  4. 组合不合法自动回落：任何时刻出现「单打×1/2/3人下」这种组合（含两人各改一项并发拼出来的），谁下自动落回全上全下，抽屉如实显示
- **禁止**：在打的对局被自动作废重排（要废只有全权者手动取消对局——2.2 场景 4.12）。

### 场景 4.8：各种状态的人在发牌里的落实（自动；兑现 2.2 已定行为）
- **身份**：全场（无需操作）
- **前提**：候场队里什么人都有——歇着的、想连打的、刚来的、被换下的
- **操作**：无
- **结果**：
  - **休息跳轮**：轮到发牌给他时跳过这一轮、消耗一次，坑由下一位顶上；按几次跳几轮、可取消（2.2 已定）
  - **连战**：设了的人下次发牌排最前（2.2 已定）
  - **进队规矩**：迟到、中途加入、被换下的排队尾；作废对局回流的人排队首（均 2.2 已定）
  - **访客**：与正式球友完全同规——上下场、按资历、连庄照算（2026-10-07 终裁，2.2 §4.13 已按此改写）
  - **未到、早退、移出名册**：不进发牌池（2.2 已定）
- **禁止**：跳轮的人占着坑位导致发不满（跳过就把坑给下一位）。

### 场景 4.9：手动换人之后，自动怎么接管（自动）
- **身份**：全场（换人动作本身 2.2 已定：球友可换、留名进战报）
- **前提**：有人刚手动换了人，或全权者点了一键排阵
- **操作**：无
- **结果**：
  - 换人后这片按新阵容接着打；换上的人资历从换上那刻起算，被换下的人排队尾（2.2 已定）；**手动换人不动该队的连庄**——队照算、到点照下
  - 这片下一场照常自动发牌——按当前「谁下／怎么配」和新阵容的资历算，**不会把人手动换的阵容再改回去**
  - 一键排阵：空着的片按当前方式一次补满（2.2 已定）
- **禁止**：自动发牌推翻刚换上的任何人（除非他自己的状态该下——跳轮、到点等规则照算）。

- 误选了不合适的：随时再点换回来即可，无确认弹窗、无危险动作（本册不含作废/清零类按钮）。

### 附录 B：后端行为

**B1. 触发与响应**
- 签到、早退、移出、片数变化、确认结束对局 → 总账当场重算推荐与候场队，几秒内全场各手机一致。

- 断网/失败：提示可重试；结束对局重试只落一次账、下场的人不重复进队。

- 几百人的现场（远超微信群场景）：发牌与推荐本身仍是总账瞬间算的，先扛不住的是画面同步与战报刷屏；慢而不错——总账不乱，轮换照样只有一本账。
