# 2.1 打球页 — 前端

## 一、总纲

打球页干一件事：把现场管起来——谁在场、谁上场、和谁一边、几比几，一屏全有、随手可改。

## 二、核心功能

### 1. 签到进场

把报名的人变成到场的人。入口两个：约球页点进本局、现场扫组织者二维码。空降者扫同一张码，填个称呼即可进局，按访客计（积分打折、费用照摊）。组织者侧的迟到签到、代人带客，同归此模块。

- **约球页进**：球局开打后，从我的局点进现场（通 3.1）。
- **现场扫码**：组织者亮出本局二维码（手机出示或打印贴场地边），扫完即到场，直接进候场区。
- **空降通道**：没报名的人扫同一张码，填个称呼就能进局，按访客计——积分打半折（输了少扣，朋友第一印象要紧），费用照常摊。
- **组织者代办**：迟到的人由组织者逐个点【到场】，迟到时长自动累计；代人带客也在这办，访客直接进候场区。


### 2. 场地对局卡

每片场一张卡，显示对阵与比分，谁得分点谁那边，一键终局。

- 卡头：场地号（订过场的局直接带 3.2 登记的场地号）、单/双打、分制、连庄数。
- 卡中：左队头像列 — 大比分（领先方高亮）— 右队。
- 记分按钮贴着队伍放，不用选人。
- 终局判定：先到分制数且净胜 2 分才算赢（封顶防无限拉锯），到点即转结算；也留【取消对局】——人回流候场、不计积分。
- 两人同时记分，以后端到达顺序为准，本地先更新再对齐；球馆信号差是常态，记分先暂存本地、恢复后同步。
- 第一版只有组织者能记分，结构上预留开放给场上任意人。

### 3. 候场区

到场者按轮转次序排队，下一位高亮，普通球友可看"还有几轮到我"。

- 角标区分休息中 / 访客，显示已打 N 场。
- 迟到者签到前暗显，组织者点【到场】后入队；提前退的灰显留记录。
- 候场区空了显示"全员都在场上"，不是报错。

### 4. 排阵控制

自动——人够一键派四人下场，算法在后端，前端只做触发与呈现；手动——换人，供组织者兜底纠偏。

- **自动**：算法在后端——上场次数少者优先、按积分蛇形分两队防两高手一边倒，胜者留场 / 均衡 / 随机混搭三模式可切。前端只做按钮和结果呈现。
- **手动**：换人——场上↔候场互换，或指定下一场谁上。自动排得离谱时（新人没积分、有人临时有事），这是组织者兜底的抓手。
- 人不够开打：卡上显示"还差 N 人 · 候场 X / 需 4 人"，带【去约球页拉人】按钮（通 3.1）。

### 5. 终局结算

点选胜方、预览每人积分增减、确认后落账，并排好下一场。

- 终局弹窗：点选胜方、比分可改、每人 ±积分实时预览（注明访客半权重、输家少扣）。
- 【确认终局·排下一场】：积分落账，下一场已排好，输家回候场队尾。
- 球局打完转收尾态，引导去战报和费用结算，入口移出底部导航。

主线一句话：签到收人 → 候场排队 → 排阵上场 → 记分 → 收局落账，循环到散场。

## 三、辅助功能

- **信息栏完整版**：点顶条展开——计时、场地加减、规则修改（分制、单双打、轮换模式），现场变更当场生效。（帮：场地对局卡）
- **滚动战报**：顶条轮播刚结束的比分，晚看手机的人几秒补完进展。（帮：候场区、全体）
- **个人状态开关**：候场区点人可设歇两轮、连战、提前退场，作为换人之外的微调。（帮：候场区）

## 四、页面设计

操作一条规律：**点啥出啥**——点比分记分、点人管人、点顶条改局，只有收局才弹窗。

**一屏三块**
- 顶条：局名、场馆、第 N 轮、在场人数；最右常驻二维码按钮；点顶条展开设置（计时、场地加减、改规则）
- 场地卡区：每片场一卡，比分最大字，卡脚即记分/终局；组织者见操作版，球友见只读版；空闲态显示"还差 N 人开打"和【自动排阵】
- 候场条：置底常驻，写"下一场"人选，下几位待上场高亮，快轮到我时变粗；【+ 到场】入口在此

**二维码浮层**：点顶条右侧按钮出大图二维码 + 局名、场馆、在场人数，方便出示、投屏；已到场者皆可亮。

**抽屉**
- 点人：点任何人出——换人 / 歇两轮 / 连战 / 退场
- 签到：从【+ 到场】进——迟到者逐个【到场】、带访客、空降登记

**弹窗（唯一）**
- 终局结算：点胜方、积分预览、【确认终局·排下一场】/【取消对局】

**登记页**：扫码的人先落这——选"我是名单里的"或"我空降"，填称呼即进现场（流程页替代弹窗）。

**入口**
- 约球页 → 我的局 → 球局进行中 → 进现场
- 现场扫二维码 → 登记页 → 现场

## 五、用户故事（当验收用）

1. **老王开场**：开打前点出本局二维码 → 球友陆续扫码到场进候场区 → 小刘迟到，老王点【到场】 → 空降的小陈扫码填称呼进局（访客，积分打折、费用照摊）→ 人够了点【自动排阵】，A 场开打。
2. **小张记分收局**：A 场打到 10:9 → 老王点左队【记 1 分】，11:9 净胜 2 到点 → 终局弹窗点胜方、看每人 ±积分 → 【确认终局·排下一场】 → 下一场已排好，输家回候场队尾。
3. **小李候场**：小李打完一场坐场边 → 打开 app 直接落进打球页 → 候场区看到"还有 2 轮到我" → 字幕滚过刚才的比分，几秒补完进展。
4. **老王纠偏**：自动排阵把两个新手排一边 → 老王从候场区点小张，换下场上的小陈 → 对阵重排。
