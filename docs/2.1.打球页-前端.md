# 2.1 打球页 — 前端

编号 2.1 · 2026-10-03 · 状态：草稿

球局进行中的现场指挥台：谁在场、谁上场、和谁一边、几比几，一屏全有、随手可改。
已签到的球友打开应用直接落进这页（1.5 定的最高优先级——此刻只关心比分、轮次、什么时候轮到我）；组织者全程在这排阵、记分、终局；迟到的到候场区签到即入排阵。游客不进，外人看的是战报（另做）。

## 页面内容（自上而下）

- **局况横幅**：LIVE 灯 + 第 N 轮 + 计时器；局名、场馆（如"夜光局 · GLOW ARENA 3 号馆"）、开打时间、组织者、在场人数。片数步进器（1–8 片）局中随时加减。规则 chips（11 分制 / 双打 / 轮换模式），点「调整规则」开维护弹层：改分制（11/15/21，注明平后需净胜 2 分）、轮换模式三选、单双打，应用后当场生效——规则不是建局时定死的，现场改是常态。
- **场地对局区**：每片场一张卡（A/B/C/D…）。已订场的局（3.2 订场登记）卡头直接带登记的场地号（如「3号 · 打球中」），开打片数默认取登记的片数，现场照旧可加减（2026-10-04 订场改版）。
  - 空闲态：人够时大按钮【自动排阵】（按均衡度派下 4 位）；人不够就显示"还差 N 人开打 · 候场 X / 需 4 人"，带个【去约球页拉人 →】按钮（通 3.1）。
  - 对局态：卡头是场地号、单/双打、分制、连庄标记（👑×N）、本场计时；中间左队头像列 — 大比分（领先方高亮）— 右队；双方到 cap−1 且分差 <2 时亮 DEUCE 标。卡脚三个按钮：记 1 分·左队 ｜ 终局 ｜ 记 1 分·右队——记分按钮贴着队伍放，谁得分点谁那边，不用选人。
  - 终局瞬间：卡片闪一下撒个花，Toast"终局 X:Y · ELO 已结算 · 下一场已排好"。
- **均衡引擎**：
  - 圆环指数 0–100，按在场人员上场次数的标准差算——人人打得一样多就是 100。
  - 一句话规则：上场次数最少者优先 · 久候者优先 · 休息/连战标记已计入权重。
  - 配每人上场次数的小条图（休息中灰显、未到暗显）。指数掉了 = 组织者该手动干预了（换人、按住某人休息）。
- **候场区**：按均衡度排序，下一位高亮；角标区分休息剩 N 轮 / 连战 / 访客，显示已打 N 场。
  - 休息中：月亮图标，"跳过 N 轮后自动归队"+【提前归队】。
  - 迟到：实时累计迟到分钟 +【到场签到】——来没来、几点走的清清楚楚。提前退的灰显留记录不留操作。
  - 轻点队员出操作：休息一轮 / 标记连战 / 换人 / 退场 / 查看战力档案（通 5.1）。
- **战况跑马灯**：横幅滚"阿凯/大川 11:8 拿下 A 场"，刚看手机的人 3 秒补完刚才发生了什么。

## 规则（匹克球特化，写死在交互里）

- 11 分制默认（15/21 可选），净胜 2 分制胜：先到 11 还得拉开 2 分才算赢，封顶 cap+9 防无限 deuce。匹克球没有"先到 11 就赢"，DEUCE 徽标就在这一刻亮。
- 双打默认，一片场 4 人（单打 2 人），候场需求人数跟着单双打切。
- 胜者留场（Kings Court）：民间最普及的玩法——赢家连庄守擂、输家回队尾，连庄数上皇冠。
- 均衡轮转：蛇形组队，按 Elo 降序蛇形分两队，防两高手一边碾新手。
- 随机混搭：盲盒配对。三种模式现场随时切。
- 访客半权重：Elo 结算减半（输了少扣），费用照常 AA——朋友带来的新人第一印象要紧。
- 终局弹层：点选胜方、比分可改、每人 ±Elo 实时预览（注明访客半权重、输家少扣的俱乐部友好制），【确认终局·排下一场】；也留【取消对局】——人回流候场、不计 ELO。
- 签到/带人弹层：迟到者逐个【到场】；带人填访客称呼（可空自动命名）+ 数量 stepper + 介绍人 chips，访客直接进候场区、费用照常入账。

## 边界

- 两人同时记分：后端到达顺序为准，本地先乐观更新再刷新对齐。
- 球馆信号差是常态：显示上次状态标"恢复后同步"，记分离线暂存。
- 候场区空了显示"全员都在场上"，不是报错；场地全空就引导去拉人或开签到弹层。
- 球局结束转收尾态，引导去战报/结算，入口移出底部导航。

## 分期

第一版只做：横幅、场地对局（记分+终局+Elo 预估）、候场区、均衡排阵（含蛇形组队）、维护弹层，手动换人可先不做（自动排阵够用）。跑马灯、参与者自助记分、动效打磨二期再说。
