## 一、总纲

打球页干一件事：把现场管起来——谁在场、谁上场、和谁一边、几比几，一屏全有、随手可改。

## 二、核心功能

### 1. 签到进场

把报名的人变成到场的人。入口两个：约球页点进本局、现场扫组织者二维码。空降者扫同一张码，填个称呼即可进局，按访客计（积分打折、费用照摊）。组织者侧的迟到签到、代人带客，同归此模块。

- **约球页进**：球局开打后，从我的局点进现场（通 3.1）。
- **现场扫码**：组织者亮出本局二维码（手机出示或打印贴场地边），扫完即到场，直接进候场区。
- **空降通道**：没报名的人扫同一张码，填个称呼就能进局，按访客计——积分打半折（输了少扣，朋友第一印象要紧），费用照常摊。
- **组织者代办**：迟到的人由组织者逐个点【到场】，迟到时长自动累计；代人带客也在这办，访客直接进候场区。


### 2. 场地对局卡

一个局 1~n 片场地**同时开赛**：每片场一张卡，显示对阵与比分，谁得分点谁那边，各自记分、各自一键结束对局，互不等待。开几片以现场事实为准——订场登记（3.2）的场地数只是默认参考和场地号来源，**不必然等于开打片数**：人够就多开一片，场收了就少开，实际打几片记几片。

- 卡头：场地号（订过场的局直接带 3.2 登记的场地号）、单/双打、分制、连庄数。
- 卡中：左队头像列 — 大比分（领先方高亮）— 右队。
- 记分按钮贴着队伍放，不用选人。
- 对局结束判定：先到分制数且净胜 2 分才算赢（封顶防无限拉锯），到点即转结算；也留【取消对局】——人回流候场、不计积分。
- 两人同时记分，以后端到达顺序为准，本地先更新再对齐；球馆信号差是常态，记分先暂存本地、恢复后同步。
- 第一版只有组织者能记分，结构上预留开放给场上任意人。

### 3. 候场区

到场者按轮转次序排队，下一位高亮，普通球友可看自己的候场排位。

- 角标区分休息中 / 访客，显示已打 N 场。
- 迟到者签到前暗显，组织者点【到场】后入队；提前退的灰显留记录。
- 候场区空了显示"全员都在场上"，不是报错。

### 4. 排阵控制

自动——人够就把能开的片一次排满（一个场地两/四人下场对局），算法在后端，前端只做触发与呈现；手动——换人，供组织者兜底纠偏。

- **自动**：算法在后端——上场次数少者优先、按积分蛇形分两队防两高手一边倒，胜者留场 / 均衡 / 随机混搭三模式可切。前端只做按钮和结果呈现。
- **手动**：换人——场上↔候场互换，或指定下一场谁上。自动排得离谱时（新人没积分、有人临时有事），这是组织者兜底的抓手。
- 人不够开打：卡上显示"还差 N 人 · 候场 X / 需 4 人"，带【去约球页拉人】按钮（通 3.1）。

### 5. 结束对局与结算

点选胜方、预览每人积分增减、确认后落账，候场够人即排好该场地的下一场对局，各场地互不等待。

- 结算弹窗：点选胜方、比分可改、每人 ±积分实时预览（注明访客半权重、输家少扣）。
- 【确认结束·排下一场】：积分落账，该场地的下一场对局已经排好，输家回候场队尾。
- 球局打完转收尾态，引导去战报和费用结算，入口移出底部导航。

主线一句话：签到收人 → 候场排队 → 排阵上场 → 记分 → 结束对局落账，循环到散场。

## 三、辅助功能

- **信息栏完整版**：点顶条展开——计时、场地加减、规则修改（分制、单双打、轮换模式），现场变更当场生效。（帮：场地对局卡）
- **滚动战报**：顶条轮播刚结束的比分，晚看手机的人几秒补完进展。（帮：候场区、全体）
- **个人状态开关**：候场区点人可设歇两场、连战、提前退场，作为换人之外的微调。（帮：候场区）

## 四、页面设计

操作一条规律：**点啥出啥**——点比分记分、点人管人、点顶条改局，只有收局才弹窗。

**一屏三块**
- 顶条：局名、场馆；最右常驻二维码按钮；**遥测三格常驻**——剩余时间倒计时、打球场地直填、赛制模式入口（改规则进抽屉），现场要瞄的信息不用点开（修订①，见文末）
- 场地卡区：每片场一卡，比分最大字，卡底记分框**点数字=该队+1**；组织者见操作版，球友见只读版；空闲态显示"还差 N 人开打"和【自动排阵】
- 候场条：置底常驻，写"下一场"人选，下几位待上场高亮，快到我时变粗；【+ 到场】入口在此

**二维码浮层**：点顶条右侧按钮出大图二维码 + 局名、场馆、在场人数，方便出示、投屏；已到场者皆可亮。

**抽屉**
- 点人：点任何人出——换人 / 歇两场 / 连战 / 退场
- 签到：从【+ 到场】进——迟到者逐个【到场】、带访客、空降登记

**弹窗（唯一）**
- 结算弹窗：点胜方、积分预览、【确认结束·排下一场】/【取消对局】

**登记页**：扫码的人先落这——选"我是名单里的"或"我空降"，填称呼即进现场（流程页替代弹窗）。

**入口**
- 约球页 → 我的局 → 球局进行中 → 进现场
- 现场扫二维码 → 登记页 → 现场

## 五、用户故事（当验收用）

1. **老王开场** [x]：深链进局现场自动点亮 → 球友陆续到场进候场区 → 迟到的人由【＋到场】签到抽屉逐个点【到场】（自动记迟到、排队尾）→ 组织者在同抽屉「带访客」填称呼带上场（访客积分半折、费用照摊）→ 候场够了点空闲卡【自动排阵】开打。
2. **小张记分结束对局** [x]：点左队大数字记到 11:9 → 自动弹结算弹窗 → 点胜方、看每人 ±积分 → 【确认结束·排下一场】→ 积分落账（战力榜实时联动）、该场地的下一场对局自动排好，输家回候场队尾。
3. **小李候场** [x]：打完一场坐场边 → 打开 app 直落打球页 → 候场条见自己的排位（快到我变粗）→ 顶条跑马灯滚过刚才的比分。
4. **老王纠偏** [x]：点候场的人出抽屉 → 【换人】→ 从场上四人里点一个 → 两边互换、对阵重排。

## 六、实现修订记录（2026-10-05，原型 vs 本文冲突的落地裁决）

1. **设置入口**：原「点顶条展开设置」→ 改为**遥测三格常驻顶条**（剩余时间/场地直填/赛制模式），改规则收进规则抽屉。理由：剩多久、几片场、什么模式是现场高频瞄一眼的信息，藏进二级层多一次点击；原型即此形态。在场人数移到二维码浮层（出示场景才需要）。
2. **记分**：原「记分按钮贴着队伍放」→ 卡底记分框**比分即按钮**（点数字=该队+1），另保留【撤一分】（原型只有清零，误触一下全清损失过大——撤回最后得分方一分）。
3. **歇两场**（原「歇两轮」，2026-10-07 随轮概念作废改称，见修订⑨）：跳过两场属于我的发牌后自动归队（旧代码是歇一次自动归队）。
4. **结束对局流程**：旧实现到分自动落账弹结果卡；按本文 §5 落地为**确认制**——到分先弹结算窗（点胜方/改比分/±积分预览），确认才落账并自动排下一场；【取消对局】人回流候场不计积分。
5. **迟到/中途加入的发牌**：旧口径迟到、中途加入的人永远不进发牌池（进队但排不上）；修正为**到场者都进发牌池**（迟到排队尾等一场），只有未到/早退不发。
6. **登记页（本文 §四）本轮未实现**（原型未含该页）：扫码直达打球页，游客点【＋到场】先走名片建号（1.1 A1）再自动到场；「空降」暂由组织者「带访客」承载。后续要做登记页另立规格。
7. **换人**：原型留白（"另接"）；按本文核心功能 4 落地为最简互换——点人→换人→选对侧一人→互换位置。
8. **片场并行模型（2026-10-07 产品裁决）**：一个局 1~n 片场地**同时开赛**；订场登记的场地数与实际开打片数不必然等同，以现场事实发生为准（§2/§4/§5 已按此改写，与《2.2》并行口径一致）。现实现承 alpha 是**单记分板串行流水**——同一时刻只有一片上记分板（cur），其余为预排待开片（NEXT·待开打），上一场结束对局才顶上——与裁决不符，属待改造偏差；现场改造（含 1.3 现场后端规格立项）按并行模型重造：每片独立记分流、各自结束对局、各自排下一场。
9. **术语收口（2026-10-07，以 0号 术语表为准）**：①「轮」概念作废——顶条「第 N 轮」、候场「还有几轮到我」退场（候场改看排位），歇两轮改称**歇两场**（跳过两场属于我的发牌后自动归队）；②「终局」弃用（「局」字与球局/对局错位）——一场对局打完的确认动作叫**结束对局**（按钮【确认结束·排下一场】），弹窗叫结算弹窗，全场收工叫**散场**；③片只数场地、场才数对局。现实现文案（顶条第 N 轮、歇两轮 toast、「还有 N 轮」、确认终局按钮）待并行重造批次同步。
