# 第一部分：全系统用户行为场景全景汇总

> 本部分用人话把全系统所有可能发生的情景与期待结果按业务域归纳，供测试前核对事实全貌与设计边界。

## 域 A：账号、身份与隐私（来源：1.1 / 1.6 / 1.7 / 1.4 / 5.1）
- **S01 游客看局免登**：微信群点开球局链接，时间/地点/名单（只显昵称）直接可见，全程零弹窗拦截；局不存在给明白话说明页，已结束局历史战绩照常看。`[1.1 §4.1]`
- **S02 名片三行建号**：游客点报名或建局，弹半屏名片卡（昵称可跳过、预设头像可跳过、11位手机号必填），点确定建号与报名一步搞定，下次免密；卡片右上角【登录】任何打开姿势都亮，老球友点了直达登录页、登完回来刚才的报名自动接着办、已填内容不丢。`[1.1 §4.2 / 1.6 §4.2]`
- **S03 老球友免密直进**：已建号设备再次点开任意局链接，秒认出身份，战绩资料全在，零输入步骤。`[1.1 §4.3]`
- **S04 换设备找回（双栏）**：新手机点登录，登录页两栏并列「收验证码」「用密码」；输手机号收 6 位验证码（60s倒计时冷却，发太频繁提示稍候）；若库中无账号明确提示核对重输，绝不静默建空号；连错5次熔断作废。`[1.1 §4.4 / 1.6 §4.4]`
- **S05 手机号冲突接管（三出口）**：报名填手机号提示占用，占卡给三个证明出口任选——【用短信验证，进入那个账号】【用密码进入】【微信验证进入（即将开通）】+【不是我的号？返回重填】；验过即接管：刚才点的报名自动继续完成、刚填名片项覆盖冒填者留下的、旧设备免密钥匙连同旧密码立即全作废。`[1.1 §4.5 / 1.6 §4.5]`
- **S06 隐私脱敏与注销**：他人名片与名单至多见尾号 4 位，仅本人可见完整 11 位；注销账号经说明与短信确认后生效，各处名字变「已注销球友」，手机号释放；密码不示人——任何界面只可改不可看，输入框掩码。`[1.1 §4.6 / 1.6 §6 / 5.1 §4]`
- **S50 设置密码**：设置页密码区块「未设置」点【设置密码】，收一条短信码+设 6 位以上密码（纯数字也行，两遍一致），区块翻「已设置」；刚验完短信的同一回操作内不再发第二条码。`[1.6 §4.8]`
- **S51 用密码登录与锁定**：登录页切「用密码」栏手机号+密码直进；密码错提示剩余次数，连错 5 次锁一刻钟（提示还剩多久、指引用短信进），锁的只是密码路，「收验证码」栏照常能进。`[1.6 §4.9]`
- **S52 忘记密码重置与改密**：「用密码」栏【忘记密码】三步（手机号→收码→新密码）=换锁：所有设备钥匙作废只留当前台，重置成功提示"其他设备下次要重新登录一次"；设置页【修改密码】验旧密例行生效，其他设备无感、旧密错不锁只提示重输。`[1.6 §4.10, §4.11]`
- **S56 微信一键登录**：登录页与名片卡的微信键（通道配置后自动点亮，未配置点着只说明）——微信里点两下（跳微信确认页→允许→跳回）直接进绑过的账号，名片战绩原样、进行到一半的动作接着办（办不成的回来说明原因）；没绑过的落现有名片卡：新面孔填卡建号顺手绑上（绑定真成了才提示「已绑上」），老球友点右上角「登录」走短信或密码，验证完自动正式绑上；不在微信里点只说明「在微信里打开才能用」不跳转。`[1.7 §4.1~§4.3]`
- **S57 占卡微信验证进入**：占卡态第三出口——微信正式绑在这个号上则接管进入，效果与短信出口完全一致（明确填过的名片并入、全设备旧记忆连同密码作废、宽限窗、挂起动作接着办）；没绑过/绑在别的账号/只是建号顺手绑，各一句指路不拼句，短信密码出口照常；走完任一验证后微信换绑到当前账号（原先那个账号的绑定自动解开）。`[1.7 §4.4, §4.5]`
- **S58 微信绑定两档与清场**：建号顺手绑只当「没验过身份」用（比本机记忆更能跨设备，故真主人任何一次验明正身（短信/密码/换锁）自动解开——冒填者的微信进不来，本人再走一遍验证即重新正式绑上）；短信/密码验证时刻绑的是牢靠绑（换锁不清、日常进门不踢设备不废密码；怀疑微信被盗走短信接管断开）；短信/密码接管与注销清登记位（微信接管不清——绑定就是这次的进门凭证）。`[1.7 §4.9, §4.10, C3]`

## 域 B：组局、找局与报名（来源：1.2 / 3.1 / 3.2）
- **S07 组织者发新局**：约球页点「+」，填时间（起止时刻滚轮）、截止（默认开打前2小时）、地点、人数（最少-最多）、规则三件（分制、轮转方式、得分规则）、可见档（跟我打过/任何人/仅邀请）；组织者占第1坑，费用显未定。`[1.2 §4.1, 3.2 §2.1]`
- **S08 找局三档可见性**：「任何人」人人可见；「跟我打过」需同在一个已成局正式名单过的人才可见；「仅邀请」公开不出现；任何档只要拿到分享链接点开都能看能报。`[1.2 §4.2]`
- **S09 报名带朋友**：球友点加入可选带人（最多带3人），整行算坑；若剩余坑位不够整行，整行落候补并提示「坑不够，已为你排候补」，不拆行。`[1.2 §4.3]`
- **S10 正常退局**：截止前球友点退出，名额释放，候补第一位整行自动转正。`[1.2 §4.4]`
- **S11 截止防鸽锁死**：截止时刻过后名单锁死，参加者不可退出；组织者任何时候无退出按钮。`[1.2 §4.4]`
- **S12 改局与改约解锁**：组织者开打前可改时间地点人数；上限改大候补转正，改小后报者转候补；截止后若改动时间或地点，名单解锁，参加者获得一次退出权。`[1.2 §4.6]`
- **S13 锁定必打与订场**：组织者面板三态：未锁；空锁（人不够也必开）；订场锁（场地号逐框填、填完自动添框识别N片+总价实时算人均，2026-10-10 改逐框）；保存即必开，场地号亮给球友（局卡时间下亮号）；清空登记退回待定但手动锁不松。`[1.2 §4.7, 3.2 §2.3]`
- **S14 截止生死懒判定**：到截止时刻，任何人打开/刷新时判定：够最少人数或必打局名单锁定成局；不够人数且非必打局自动终止，报名者变灰字「该局已取消」。`[1.2 §4.8]`
- **S15 救局恢复与撤局**：自动终止的局在开打前组织者可点恢复进待处置；主动撤局过二次确认（已订场的局确认框里提醒去场馆退订），撤局后组织者不留痕。`[1.2 §4.9, §4.10]`
- **S16 打球意向簿与邀请**：球友留/改/删意向（时段+频率+备注）；组织者翻意向挑人点邀请，局进对方「我的局」提示有人邀请，点加入才占坑；改意向自动清已邀标重排前列。`[1.2 §4.11-4.13]`

## 域 C：开场、入场与签到（来源：2.1 / 2.2 / 2.5）
- **S17 约球卡片时态**：距开打 >2 小时显倒计时且无入场按钮；≤2 小时且必开局亮【进入现场】；未定必开局维持倒计时。`[2.5 §4.1-4.3]`
- **S18 组织者提前开账**：必开局组织者随时可点【开始打球】点亮现场，全体报名者卡片同步变进入现场；报名中局组织者点开始提示「先锁定必打」。`[2.5 §4.4]`
- **S19 点进现场 ≠ 签到**：球友进现场只看不签不进候场队，候场人数为 0，人未到不上场。`[2.5 §4.2]`
- **S20 首签当临时管家**：账开后首位在候场条点「我到了」的球友，提示「已签到」，并弹卡「组织者还没来·现场你先管着」，头像带管理员标，顶条播报，组织者到场可收回。`[2.5 §4.2, §4.6]`
- **S21 到点点进即开**：开打时刻后无人开账的必开局，任何报名者点进现场系统顺手开账，绝无死锁。`[2.5 §4.5]`
- **S22 现场扫码与空降**：顶条出示大图码；老球友扫码进现场点「我到了」即到场；未报名朋友扫码填名片（含手机号）直接入册，带「空降」标排队尾，名册超限亦放行，线上名单不动。`[2.1 §2.1, 2.2 §4.2, §4.4]`
- **S23 候补扫码空降**：候补者在 App 卡片无签到入口；到现场扫码空降入册是其唯一上场路（递补转正后身份已变、按正式球友规矩走，不算候补的路）。`[2.5 §4.8]`
- **S24 代办签到早退与带客**：组织者/管理员在抽屉可代办到场、代带随行访客（挂担保人名下入队）、代办早退（移出场上与候场并落离场时刻）。`[2.1 §2.1, 2.2 §4.3]`

## 域 D：现场轮换、记分与对局（来源：2.1 / 2.2 / 2.3 / 2.4 / 1.4）
- **S25 多片独立记分卡**：每片场独立卡片，点比分大字本地加1分（已签到的球友即可记；记在各自手机上，零联网零延迟），记分框中间仅留冒号与撤回；点撤回按流水历史栈倒退得分（支持连续撤回到底，0:0 禁用置灰）；多片并行记分互不影响。`[2.3 §4.1, §8 修订]`
