# 5.1 我的页 — 前端

## 一、总纲

我的页管一个人的底账：长什么样、打过什么球、花过什么钱、账号还在不在。

**装扮形象**是我的脸面——约球页的名单、意向卡上别人看到的就是它；**账单**和**打球记录**是我的底账——里面每一行都是别的页打出来的；**账号操作**是退路——走的时候干净利落。


## 二、核心功能

### 1. 装扮形象

我的脸面。局名单、意向卡、别人点开的档案卡，露出的都是这个形象。

- 挑形象、背景图：选择一个头像和卡片背景，可切换预览，昵称这些基本信息也在这改。保存后同步更新。
- 未来可能付费（如头像）。

### 2. 账单

我花钱的底账。打了多少局、摊了多少钱、还欠没欠，一眼看清。

- 总览三个数：应付（红，我还欠的）、已付（结清了的）、该收（黄，我垫的钱别人该还我）。
- 逐笔列表：一笔一行——哪局、多少钱、什么状态（待付 / 已付 / 该收 / 已收），倒序排。
- 点开一笔看明细：进入原参加场次页，查看这场局总价多少，怎么摊的、名单里有谁。

### 3. 参加登记和打球记录

- 参加登记：已报名/组局未开场的局一屏看全。
- 打球记录：一场一行按时间倒序，内容样式沿用约球页，点击进入后看的是打球页的最终内容。

### 4. 退出和注销

来去自由的底线。

- 退出账号：当前设备登出。
- 注销账号：永久删除、不可恢复。入口放深一层防误触；先看后果说明（形象、记录、账单各自怎么处理），再二次确认；还有应付没结时，先提示去结清。
- 小程序端需要用户微信授权登录，使小程序、h5和app端账号通用。
- 修改密码

## 三、辅助功能

- **账单筛选**：账单按期间（近 7 天 / 近 30 天 / 全部），登记按状态，记录按时间——翻旧账快。（帮：账单、记录）
- **账单结算**：账单支持结算，结算后应付变已付，该收变已收。（帮：账单），参与者不存在垫付，组织者才有垫付未收。

## 四、页面设计

**我的页（底部 tab「我的」）**

- 头部形象区：装扮形象大图 + 昵称 + 「装扮」入口，点形象即进装扮页
- 账单卡：一行三个数——应付（红）· 已付 · 该收（绿），点进账单页
- 记录双卡：参加登记（共 N 局 · 签到 N 次）、打球记录（累计 N 场），点进各自页
- 底部账号区：「退出账号」；「注销账号」，防误触，修改密码和微信授权

**子页面**

- 装扮页：形象预览大图（可切"别人看到的档案卡"效果）+ 分类装扮件（脸、配件等），即点即换即见，保存后全局同步换新
- 账单页：期间筛选 + 三个总览数 + 逐笔列表，点一笔看摊账明细
- 参加登记页：与原约球页基本一致，局卡可点击进入原约球详情页
- 打球记录页：与原打球页基本一致，局卡可点击进入原打球详情页和结算页
- 修改密码页：修改密码
- 微信授权页：微信授权登录

**抽屉**
形象预览显示完整别人看到自己卡片，与打球页名单点击一致

**弹窗**

- 退出账号确认：说清"只是这台设备登出，数据都在"
- 注销账号确认：后果说明 + 二次确认，两步都过才执行

## 五、用户故事（当验收用）

写完拿这四个故事走一遍，每一步都得有地方落：

1. **小刘换脸**：从微信群挪过来 → 我的页点形象 → 装扮页挑脸、配件 → 保存 → 去约球页留个意向 → 意向卡上别人看到的就是新形象。
2. **小赵对账**：打了一个月 → 账单卡上应付红字 ¥86 → 点进账单页，筛近 30 天逐笔看 → 微信里转给垫付的老王 → 这笔变已付，应付归零，心里踏实。
3. **老王翻记录**：想看自己打了多少 → 打球记录页看到累计 42 场 → 点开上周六那场看比分 → 同一场在参加登记里写着"签到 19:02 · 早退 21:30" → 来没来、几点走，清清楚楚。
4. **小陈退场**：换手机 → 只点退出账号，新手机登回来一切原样；真不想用了 → 找到注销入口 → 看完后果说明 → 二次确认 → 干净走人。

四个故事走通，这页就成了。
