# 4.1 战力页 — 前端

## 一、总纲

战力页负责把一场场球的成绩，量化成个人水平，使用 DUPR（核心轨）/ Elo（娱乐轨）双轨制（1.4）。同时也是个人头像形象和战绩展示。

## 二、核心功能

### 1. 我的战力卡

展示形象和卡片背景，更换形象和背景，作为付费头像和背景的展示页。也展示自己运动的相关数据，包括胜负、运动时长和推算消耗卡路里，以及成绩积分。

### 2. 打架图和榜单

圈子每个人的水平量化排序。。

### 3. 球员档案

点榜单行、其他页面球友成绩进的这份档案，和现场页队员卡、我的页头像唤起的是同一份——全产品共用。

## 三、辅助功能

- **分数切换**（2026-10-12 恢复修订：4.1 初版写的是「Elo 1500 / NTRP 切换」，随 1.4 双轨制推翻——现按双轨口径换对）：页头右上角胶囊在 **DUPR / Elo** 间切换，默认 DUPR。DUPR=榜单正式口径（满 5 场入榜、段位徽章、参考 · 未定级区）；Elo=娱乐视图——同一份榜单数据按 Elo 重排（无定级门槛、无段位无未定级件、不设参考区），我的战力卡主数字与前三打架图跟着切。后端榜单排序口径不变（仍 DUPR 降序，1.4 §11）。
- **喜欢标识**：点一下标记到后端，再点取消。静默单向、不通知对方；喜欢的人在约球页吃成局优先（见 3.1）。

## 四、页面设计

**战力页（主页）**
- 头部：我的战力卡——Q 版形象 + 段位徽章 + 当前分 + 一行摘要 + 排名（本月涨跌在卡底数据行，主分数行不放涨跌签——窄列放不下三件）（2026-10-12：DUPR 主数字分层——整数位原字号、小数位 80% 字号减淡；页头右上角 DUPR/Elo 切换胶囊，副标题随视图一句一行介绍两套积分（全名细节归折叠区））
- 前三榜图：Q 版群斗插画，前三名标识出名字（随视图取当前榜前三）
- 榜单：框架最多 5 行，前三行高亮，上滑显示更多，懒加载（区头不带计数/说明书小字——2026-10-12 删「点人看档案」「N 球员在榜 · 前三高亮」两条；「满 5 场自动入榜」保留）

**子页面**
- 无独立子页——往下点都是档案弹层，换形象去「我的」页。

**弹层**
- 球员档案：榜单行、打架图小人、现场页队员卡、我的页头像唤起同一份——头像 + 徽章 + 当前分 + 摘要 + 近 5 场胜负点 +【♥ 喜欢】

## 五、数据来源（2026-10-10 接真修订：mock 榜单退役；2026-10-12 增补：切换与 elo_rating）

- **榜单**：GET /api/stats/leaderboard 全量拉取（后端 DUPR 降序、同分 id 升序；行含名字/小人/卡背 + DUPR 分/未定级/场数/胜场/近 5 场/本月净胜 + **elo_rating**——Elo 娱乐轨只读值，无行回 1200），进页拉一次、失败可点重试。满 5 场入「评分排行」，不满 5 场进「参考 · 未定级」（无位次），0 场新号两区都不进。Elo 视图在前端按 elo_rating 重排（同分 id 升序），无定级门槛（1.4 §11）。
- **我的战力卡**：身份与战绩同源账号视图（登录=真账号，游客=零战绩占位「还没开张」）；排名从榜单里找我（不在榜显「—」）；底部数据行为「N 胜 N 负 · 本月 ±N」（原「运动时长/大卡」无后端真值，随演示数据退役）。Elo 视图主数字吃榜单行的 elo_rating（游客回落 1200 展示兜底）。
- **球员档案**：全产品同一份，账号 id 空间（现场抽屉传 accountId，不传名册行 id）；档案数据出自榜单缓存，缓存没有单发 /users/{id} 补拉。档案是名片面，主数字永远 DUPR 分层口径、不随战力页切换。
- **喜欢**：仍为静默单向；后端暂无此账，标记存本机（换设备不同步），档案卡/榜单行 ♥ 同步。
- **前三打架图**：榜单前三同名同源（随视图切）。

## 六、用户故事（当验收用）

写完拿这三个故事走一遍，每一步都得有地方落：

1. **小王看数据**：周六打完球 → 开战力页 → 我的卡：3 胜 1 负、运动 2 小时、推算消耗 800 大卡、积分 +18、排名 #7 → 这周的汗没白流。
2. **小李换形象**：买了个新形象 → 在我的战力卡换上，背景也换了新的 → 打球页队友点他头像 → 档案弹层里也是这个新形象——一处换，处处新。
3. **老王排阵**：人多场少，开打前开战力页 → 切到 Elo 视图看看娱乐分排名 → 切回 DUPR 榜单上滑翻全圈 → 3.5 的和 3.5 的搭一边 → 点进档案看近 5 场稳不稳 → 看中一个稳的点【♥ 喜欢】，下次组局翻意向，他排最前面。

三个故事走通，这页就成了。
