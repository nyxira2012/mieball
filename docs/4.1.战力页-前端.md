# 4.1 战力页 — 前端

## 一、总纲

战力页负责把把一场场球的成绩，量化成个人水平，使用elo算法和NTRP分级。同时也是个人头像形象和战绩展示。

## 二、核心功能

### 1. 我的战力卡

展示形象和卡片背景，更换形象和背景，作为付费头像和背景的展示页。也展示自己运动的相关数据，包括胜负、运动时长和推算消耗卡路里，以及成绩积分。

### 2. 打架图和榜单

圈子每个人的水平量化排序。。

### 3. 球员档案

点榜单行、其他页面球友成绩进的这份档案，和现场页队员卡、我的页头像唤起的是同一份——全产品共用。

## 三、辅助功能

- **分数切换**：Elo 分默认1500起，与ntrp分级切换显示，通过后端计算。
- **喜欢标识**：点一下标记到后端，再点取消。静默单向、不通知对方；喜欢的人在约球页吃成局优先（见 3.1）。

## 四、页面设计

**战力页（主页）**
- 头部：我的战力卡——Q 版形象 + 段位徽章 + 当前分 + 本月涨跌 + 一行摘要 + 排名
- 前三榜图：Q 版群斗插画，前三名标识出名字
- 榜单：框架最多 5 行，前三行高亮，上滑显示更多，懒加载

**子页面**
- 无独立子页——往下点都是档案弹层，换形象去「我的」页。

**弹层**
- 球员档案：榜单行、打架图小人、现场页队员卡、我的页头像唤起同一份——头像 + 徽章 + 当前分 + 摘要 + 近 5 场胜负点 +【♥ 喜欢】

## 五、用户故事（当验收用）

写完拿这三个故事走一遍，每一步都得有地方落：

1. **小王看数据**：周六打完球 → 开战力页 → 我的卡：3 胜 1 负、运动 2 小时、推算消耗 800 大卡、积分 +18、排名 #7 → 这周的汗没白流。
2. **小李换形象**：买了个新形象 → 在我的战力卡换上，背景也换了新的 → 打球页队友点他头像 → 档案弹层里也是这个新形象——一处换，处处新。
3. **老王排阵**：人多场少，开打前开战力页 → 切到 NTRP 分级 → 榜单上滑翻全圈 → 3.5 的和 3.5 的搭一边 → 点进档案看近 5 场稳不稳 → 看中一个稳的点【♥ 喜欢】，下次组局翻意向，他排最前面。

三个故事走通，这页就成了。
