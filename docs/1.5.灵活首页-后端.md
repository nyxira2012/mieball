首页改为「角色化动态首页」
你要求的是：首页不再是一个固定形态的页面，而是根据「我」与今晚球局的关系（角色状态）自动决定首屏长什么样。共四种状态：

1. 我是组织者 —— 首页 = 我组织的这场局
如果我发起了今晚的打球，首页展示我自己组织的球局的完整情况：也就是组织者管理视角——亮灯进度、谁表了什么态、规则、截止时间、成局按钮；成局之后则显示我这场局的进行状态与全场人数概览。核心是：我在“经营”这场局，首页给我指挥台。

2. 我是报名参与者 —— 首页 = 我被匹配的打球预约
如果我没组织、但预定/报名参加了别人组织的局，首页展示的是我作为客人的那张预约卡：这场局的时间、地点、组织者是谁、目前成局状态（亮度/人数）、我的意向状态——并且我可以在这里改主意（调整意向/退出），但看不到组织者的管理细节。我的视角是“赴约”，不是“经营”。

3. 我什么都没选 —— 首页 = 我的形象界面
如果既没组织也没报名（新用户或没表态），首页进入以我的 Q 版形象为主角的个人界面：我的小人立在首屏 C 位，配我的名字、Elo、战绩等，并提供两个出发动作——「发起一场球局」或「看看/加入今晚的局」。此时首页是“我是谁”的展示台，引导我做出第一个选择。

4. 我已签到 —— 直接进入打球现场
如果我已经签到入场，打开 App 不再有首页中间层，直接落到打球现场（live 页）——因为此刻我唯一关心的是场上比分、谁在上场、什么时候轮到我。

隐含的优先级与判断逻辑
同一时刻我可能与球局存在多重关系，判断应当有优先级：

已签到 → 直接进现场 ＞ 我是组织者 → 组织视角 ＞ 我已报名 → 预约卡 ＞ 都没有 → 形象页

即：身份越“在场”，入口越直接；越“外围”，首页越偏展示与引导。
